# 파일과 권한

<div class="summary">

- `ls -l`의 첫 열 10글자는 **파일 종류 1글자 + 소유자·그룹·기타 각 3글자(rwx)**입니다. 소유자·그룹·기타는 순서대로 `u`, `g`, `o`이고 전체는 `a`입니다.
- 권한을 바꾸는 명령은 `chmod`, 소유자·그룹을 바꾸는 명령은 `chown`·`chgrp`이고, 하위까지 적용하려면 대문자 **`-R`**입니다.
- 기본 권한은 `umask`가 정합니다. 파일은 666, 디렉터리는 777에서 umask를 뺀 값입니다.
- 특수 권한은 **Set-UID(4)**, **Set-GID(2)**, **Sticky Bit(1)** 세 가지입니다. 공유 디렉터리에서 "삭제는 자기 파일만"은 Sticky Bit입니다.

</div>

## 1. 권한 읽는 법

```
-rw-r--r--  1  ihd  ihd  1079  Jan 27 16:29  lin.sh
↑└┬┘└┬┘└┬┘     소유자 그룹
 │  │   │   └ 기타 사용자(o)
 │  │   └──── 소유 그룹(g)
 │  └──────── 소유자(u)
 └─────────── 종류: - 파일, d 디렉터리, l 심볼릭 링크
```

| 권한 | 숫자 | 파일에서의 뜻 | 디렉터리에서의 뜻 |
|---|---|---|---|
| `r` 읽기 | 4 | 내용을 볼 수 있음 | 안의 목록을 볼 수 있음 |
| `w` 쓰기 | 2 | 내용을 **수정**할 수 있음(삭제 권한이 아님) | 안에 파일을 만들고 지울 수 있음 |
| `x` 실행 | 1 | 프로그램으로 실행할 수 있음 | 안으로 들어갈 수 있음(`cd`) |

**파일의 쓰기 권한은 내용을 수정하는 권한이지 삭제 권한이 아닙니다.** 파일을 지울 수 있는지는 파일이 아니라 그 파일이 들어 있는 **디렉터리의 쓰기 권한**이 정합니다.

소유자·그룹·권한을 확인하는 명령은 `ls -l`(디렉터리 자체는 `ls -ld`)입니다.

## 2. chmod — 권한 바꾸기

**숫자 방식**은 r=4, w=2, x=1을 더한 값을 소유자·그룹·기타 순서로 씁니다.

| 값 | 권한 | 값 | 권한 |
|---|---|---|---|
| 7 | `rwx` | 4 | `r--` |
| 6 | `rw-` | 2 | `-w-` |
| 5 | `r-x` | 1 | `--x` |

**문자 방식**은 `누구` `+`(더함)/`-`(뺌)/`=`(그대로 지정) `권한`입니다.

```
$ chmod 755 file          # rwxr-xr-x
$ chmod a+x file          # 모두에게 실행 권한 추가
$ chmod g-w,o-r file      # 그룹의 쓰기, 기타의 읽기 제거
$ chmod g=r file          # 그룹 권한을 r-- 로 지정 (rw- 였다면 w가 사라짐)
$ chmod -R 755 data       # data 아래 전체에 적용 (대문자 R)
```

예제입니다. `-rw-rw-r--`를 `-rwxr-xr-x`로 바꾸려면 `chmod a+x,g-w`입니다. `a+x`로 모두에게 실행 권한을 주고(`rwxrwxr-x`), `g-w`로 그룹의 쓰기를 뺍니다.

> **함정** `chmod u+rwx,go+rx`는 그룹의 기존 쓰기 권한을 없애지 못합니다. "더하기"는 있던 권한을 지우지 않습니다.

## 3. chown·chgrp — 소유권 바꾸기

| 명령 | 하는 일 |
|---|---|
| `chown 소유자 파일` | 소유자 변경 |
| `chown 소유자:그룹 파일` | 소유자와 그룹을 한 번에 변경 (구형 표기는 `소유자.그룹`) |
| `chown :그룹 파일` | 그룹만 변경 |
| `chgrp 그룹 파일` | 그룹만 변경 |
| `-R` | 하위 디렉터리와 파일까지 모두 적용 |

`chown ihduser:kait lin.txt`의 순서는 **소유자:그룹**입니다. `chgrp`는 그룹 하나만 받으므로 `chgrp ihduser:kait` 같은 형식은 쓰지 않습니다.

> **함정** 하위까지 바꾸는 옵션은 대문자 `-R`입니다. 소문자 `-r`은 이 명령들의 재귀 옵션이 아닙니다(`chmod -r`은 읽기 권한을 뺀다는 문자 방식의 일부로 해석되어 전혀 다른 일을 합니다).

## 4. umask — 새로 만들 때의 기본 권한

새 파일은 **666**, 새 디렉터리는 **777**에서 umask 값을 빼서 만들어집니다.

| umask | 새 파일 | 새 디렉터리 |
|---|---|---|
| `0022` | 644 `-rw-r--r--` | 755 `drwxr-xr-x` |
| `0002` | 664 `-rw-rw-r--` | 775 `drwxrwxr-x` |
| `0077` | 600 `-rw-------` | 700 `drwx------` |

새 파일에는 실행 권한이 붙지 않으므로 파일에서는 666을 기준으로 뺍니다. 파일 생성 결과가 `-rw-rw-r--`이면 umask는 `0002`입니다. 현재 값은 `umask`로 확인하고, `umask 022`로 바꿉니다.

## 5. 특수 권한

| 권한 | 숫자 | 표시 | 효과 |
|---|---|---|---|
| Set-UID | 4000 | 소유자 칸의 `s` | **실행 파일**을 실행하는 동안 실행한 사람이 아니라 **파일 소유자**의 권한으로 동작합니다. 예: `/usr/bin/passwd` |
| Set-GID | 2000 | 그룹 칸의 `s` | 실행 파일이면 파일의 **소유 그룹** 권한으로 실행됩니다. **디렉터리**에 걸면 그 안에 새로 만든 파일의 그룹이 디렉터리의 그룹으로 자동 지정됩니다. |
| Sticky Bit | 1000 | 기타 칸의 `t` | **디렉터리**에 걸면 파일을 지울 때 **그 파일의 소유자(또는 root)만** 지울 수 있습니다. 예: `/tmp` |

```
$ chmod u+s a.out        # Set-UID
$ chmod g+s dir          # Set-GID
$ chmod o+t /project     # Sticky Bit (+t만 써도 됩니다)
$ chmod 3770 /project    # Set-GID(2) + Sticky Bit(1) + rwxrwx---
```

- 숫자는 맨 앞에 붙입니다. `4755`는 Set-UID + `rwxr-xr-x`입니다.
- `ls -l` 결과의 `-r-xr-sr-x`처럼 그룹 칸에 `s`가 있으면 Set-GID입니다. `root` 소유에 `tty` 그룹이라면 실행하는 동안 **tty 그룹 권한**을 갖습니다(root 권한이 아닙니다).
- 실행 권한이 없는 칸에 특수 권한이 걸리면 소문자 `s`, `t` 대신 대문자 `S`, `T`로 보입니다.

> **함정** Sticky Bit는 **디렉터리**에서 의미가 있고, 공유 디렉터리에서 "누구나 만들되 삭제는 본인 파일만"을 구현합니다. "새 파일이 자동으로 디렉터리의 그룹으로 만들어지게"는 Set-GID입니다. 두 조건이 함께 나오면 3(2+1)을 씁니다.

## 6. 계정 파일의 권한

| 파일 | 내용 | 일반 사용자 |
|---|---|---|
| `/etc/passwd` | 계정 정보(로그인 셸 포함) | 읽을 수 있음 |
| `/etc/shadow` | 암호화된 비밀번호, 만료 정보 | **읽을 수 없음** |
| `/etc/group` | 그룹 정보 | 읽을 수 있음 |

`/usr/bin/passwd`는 일반 사용자가 자기 비밀번호를 바꿀 때 `/etc/shadow`를 고쳐야 해서 Set-UID가 걸려 있습니다.

## 7. 시험 직전 점검

> - 하위까지 바꾸는 옵션은 `chmod -R`, `chown -R`, `chgrp -R`입니다(대문자).
> - `chown`의 형식은 **소유자:그룹**, `chgrp`는 그룹만 받습니다.
> - 파일의 `w`는 수정 권한이고, 삭제는 디렉터리의 `w`가 정합니다.
> - umask 0022이면 파일 644, 0002이면 664입니다.
> - 특수 권한 확인은 `ls -l`입니다. 별도의 명령이 없습니다.

## 8. OX 점검

| 문장 | 답 | 이유 |
|---|---|---|
| 파일의 쓰기 권한이 있으면 그 파일을 삭제할 수 있다. | X | 삭제는 상위 디렉터리의 쓰기 권한과 Sticky Bit가 정합니다. |
| `chmod g=r file`은 그룹 권한을 읽기만으로 만든다. | O | `=`는 지정한 값으로 바꿉니다. |
| `chown ihduser:kait file`에서 kait는 소유 그룹이다. | O | 소유자:그룹 순서입니다. |
| `chmod -r`은 하위 디렉터리까지 적용하는 옵션이다. | X | 재귀 옵션은 대문자 `-R`입니다. |
| umask가 0022이면 새 파일은 `-rw-r--r--`이다. | O | 666에서 022를 뺀 644입니다. |
| 디렉터리에 Set-GID를 걸면 새 파일의 그룹이 디렉터리의 그룹이 된다. | O | 공유 작업 디렉터리에 씁니다. |
| Sticky Bit는 일반 파일에 부여해서 쓰는 것이 일반적이다. | X | 디렉터리에 부여합니다. |
| `/etc/shadow`는 일반 사용자가 읽을 수 있다. | X | 비밀번호 정보가 있어 root만 읽을 수 있습니다. |
