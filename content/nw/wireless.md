# 무선·모바일 통신

<div class="summary">

- **무선랜 매체 접근**은 **CSMA/CA**입니다(송신 전 채널 탐색, 랜덤 백오프, 선택적 RTS/CTS). 유선 이더넷의 CSMA/CD와 구분합니다.
- **IEEE 802.11 세대**: a는 OFDM 6-54Mbps, b는 2.4GHz 저속 보완, g는 2.4GHz에서 OFDM, **ac**는 5GHz, **ad**는 60GHz, **ax는 Wi-Fi 6**(MU-MIMO, OFDMA, 1024QAM).
- **WPAN**: 블루투스 **802.15.1**, 고속 **802.15.3**, 저속(ZigBee) **802.15.4**. 10m 안팎 근거리입니다.
- **셀룰러**: 셀을 옮겨도 끊김 없이 채널을 바꾸는 것이 **핸드오프**입니다. 다중 안테나 기술은 **MIMO**입니다.
- **CR**은 빈 주파수를 찾아 쓰는 기술, **Wireless mesh network**는 애드혹 릴레이 네트워크입니다.

</div>

## 1. 무선랜 전송 방식

| 방식 | 특징 |
|---|---|
| **주파수(전파)** | **스프레드 스펙트럼**이 가장 많이 쓰임. 일반적으로 **무선랜**이라고 하면 이 방식 |
| 적외선 | 장애물이 있으면 통신이 어려움 (빛의 직진성 때문) |
| 레이저 | 점 지향성과 직진성으로 멀리 떨어진 지점(섬과 섬) 연결 |
| 협대역 | 특정 라디오 주파수를 사용하는 방식 |

> **함정** 적외선 방식은 장애물을 통과하지 못합니다. "장애물이 있어도 통신이 가능하다"는 설명은 틀립니다.

## 2. IEEE 802.11 규격

| 규격 | 특징 |
|---|---|
| **802.11a** | **OFDM**, 최소 6Mbps 최대 **54Mbps** |
| **802.11b** | **2.4GHz** 대역, 기존 낮은 전송률(1Mbps와 2Mbps)을 보완 |
| **802.11g** | **2.4GHz**에서 **OFDM**을 써 802.11b와 공존하면서 802.11a의 높은 전송률 |
| 802.11n | MIMO |
| **802.11ac** | 5GHz 대역 (60GHz가 아님) |
| **802.11ad** | **60GHz** 밀리미터파 |
| **802.11ax (Wi-Fi 6)** | 여섯 번째 표준, **MU-MIMO**, 최대 **1024QAM**, **OFDMA**, DL/UL MU-MIMO, 6GHz 비면허 대역 지원. 고해상도 스트리밍·AR/VR·온라인 게임 같은 고대역폭 서비스를 혼잡한 환경에서 처리 |
| 802.11be | 그다음 세대 |

> **함정** 60GHz 밀리미터파 스펙트럼의 새로운 물리 계층을 정의하는 것은 802.11ac가 아니라 802.11ad입니다.

**무선랜 MAC**: 송신 전 **채널을 탐색**하고 필요하면 **랜덤 백오프**를 하며 **RTS/CTS**를 옵션으로 쓰는 방식은 **CSMA/CA**입니다. CSMA/CD(충돌 검출)는 유선 이더넷, TDMA는 시분할, 토큰 패싱은 토큰 방식입니다.

## 3. WPAN

10m 이내의 짧은 거리에서 컴퓨터, 주변기기, 휴대폰, 가전제품을 무선으로 연결하는 네트워크 영역입니다. UWB, ZigBee, RFID, 블루투스가 쓰입니다. LTE-M과 NB-IoT는 저전력 광역 IoT 통신입니다.

| 표준 | 대상 |
|---|---|
| **802.15.1** | 블루투스 |
| **802.15.3** | 고속 WPAN |
| **802.15.4** | 저속 WPAN (ZigBee의 기반) |

802.11.x는 무선랜 계열, 802.16.x는 WiMAX 계열이어서 WPAN 표준이 아닙니다.

## 4. 이동통신

| 용어 | 설명 |
|---|---|
| **핸드오프** | 통화 중인 이동 단말이 셀 밖으로 이동해 다른 셀로 들어가도 **끊김 없이** 새로운 셀 기지국에 할당된 채널로 통화 채널을 바꿈 |
| 페이징 | 단말을 호출 |
| **MIMO** | 다수의 안테나로 데이터를 전송하는 **다중 안테나 신호 처리 기술** |
| OFDM | 직교 주파수 분할 다중화 |
| M2M, MQTT | 기기 간 통신, 경량 메시징 프로토콜 |

## 5. 기타 무선 개념

| 개념 | 설명 |
|---|---|
| **CR (Cognitive Radio)** | 기존 주파수 사용자에게 간섭 없이 **비어 있는 주파수를 검색해 사용**. 주파수 사용자가 쓰면 다른 대역으로 옮겨야 함 |
| **Wireless mesh networks** | 블루투스처럼 유연한 **애드혹** 네트워크. 각 장치가 다른 장치의 트래픽을 **릴레이·라우팅**. 군사 기술에서 출발, 전원만 연결하면 네트워킹, 유선망 없이 망 확장 쉬움 |
| Wireless sensor networks | 센서 노드 네트워크 |
| 감쇠(Attenuation) | 전기신호가 구리선을 지나며 **약해지는** 현상 |

## 6. 시험 직전 점검

> - 무선랜은 CSMA/CA, 유선 이더넷은 CSMA/CD.
> - 블루투스 802.15.1, 고속 WPAN 802.15.3, 저속 WPAN 802.15.4.
> - Wi-Fi 6 = 802.11ax. 60GHz = 802.11ad.
> - 셀 이동 중 끊김 방지 = 핸드오프. 다중 안테나 = MIMO.
> - 빈 주파수 활용 = CR. 애드혹 릴레이 = 무선 메시.
