# 네트워크 이론 (OSI·IP·프로토콜)

<div class="summary">

- **OSI 7계층**은 아래부터 물리 → 데이터링크 → 네트워크 → 전송 → 세션 → 표현 → 응용입니다. 전송 단위는 **bit, frame, packet, segment, data** 순입니다.
- **포트**는 `Telnet 23`, `SSH 22`, `SMTP 25`, `DNS 53`, `POP3 110`, `IMAP 143`, `SNMP 161`, `HTTPS 443`, **잘 알려진 포트는 0부터 1023**입니다.
- **IP 클래스**는 A(첫 비트 0), B(10), C(110), D(1110)이고 **루프백 127.0.0.1은 A 클래스**입니다.
- **서브넷 계산**은 블록 크기로 합니다. `/26`(255.255.255.192)이면 64개씩 끊어 **네트워크 주소 = 블록 첫 값, 브로드캐스트 = 블록 마지막 값**입니다.
- **UDP**는 확인 응답이 없고, **TCP**는 3-way handshaking(SYN → SYN/ACK → ACK)을 합니다.

</div>

## 1. OSI 7계층

| 계층 | 이름 | 전송 단위 | 하는 일 | 장비·프로토콜 |
|---|---|---|---|---|
| 7 | 응용 | data | 사용자 서비스 | HTTP, FTP, SMTP |
| 6 | **표현** | data | **암호화·복호화, 압축·해제**, 형식 변환 | |
| 5 | **세션** | data | **응용 프로그램 간 통신 관리**, 접속 설정·유지, 동기점 제공 | |
| 4 | **전송** | **segment** | 종단 간 신뢰성 | TCP, UDP |
| 3 | **네트워크** | **packet** | 경로 선택(라우팅), 연결성 | IP, ICMP, ARP, BGP, **라우터** |
| 2 | **데이터링크** | **frame** | 인접 장치 간 전송 | MAC, **브리지**, 스위치 |
| 1 | **물리** | **bit** | 전기 신호 전달 | **리피터**, 허브, 케이블 |

- **하위 계층부터 나열**: 물리 → 데이터링크 → 네트워크 → 전송 → 세션 → 표현 → 응용
- 인터네트워킹 장비를 하위 계층부터 나열하면 **리피터 → 브리지 → 라우터**입니다.
- **가장 많은 계층을 지원하는 장치는 게이트웨이**입니다(보기에 없으면 라우터). 프로토콜이 다른 통신망을 접속하는 장비도 게이트웨이이고, 가장 낮은 계층의 장치는 리피터(허브)입니다.
- **UDP는 전송 계층**이어서 네트워크 계층과 가장 거리가 먼 프로토콜입니다. ICMP, IP, ARP, BGP는 네트워크 계층에서 다룹니다.

프로토콜의 기본 구성 요소는 **구문(syntax), 의미(semantics), 순서(timing)**이고 소켓은 아닙니다.

## 2. TCP, UDP, ICMP, ARP

| 프로토콜 | 특징 |
|---|---|
| **TCP** | 연결 지향, **3-way handshaking**으로 연결 |
| **UDP** | 세그먼트를 보내기만 하고 **응답을 주고받지 않으며**, 제대로 전달됐는지 확인하지 않고 오류 수정도 하지 않음. **DNS** 등이 사용 |
| **ICMP** | **오류 보고**와 피드백을 원래 호스트에 알림(ping의 바탕) |
| **ARP** | **IP 주소를 MAC 주소로** 변환(매칭) |

**3-way handshaking**의 순서는 다음과 같습니다.

1. 클라이언트 → 서버: **SYN** (연결 요청). 받은 서버는 **half-open 상태**가 됩니다.
2. 서버 → 클라이언트: **SYN/ACK**
3. 클라이언트 → 서버: **ACK** → 연결 수립(ESTABLISHED)

## 3. 포트 번호

**잘 알려진 포트(Well-Known Port)는 0부터 1023**입니다.

| 포트 | 서비스 | 포트 | 서비스 |
|---|---|---|---|
| 20, 21 | FTP(데이터, 제어) | 110 | POP3 |
| 22 | SSH | 143 | IMAP |
| 23 | Telnet | 161 | SNMP |
| 25 | SMTP | 443 | HTTPS |
| 53 | DNS | 6000 | X Window |
| 80 | HTTP | | |

> **함정** Telnet은 **23**, SSH는 **22**입니다. 서로 바꿔서 나오는 보기가 많습니다. SNMP는 **161**(151, 53은 아님)입니다.

## 4. IPv4 주소

| 클래스 | 첫 비트 | 첫 옥텟 범위 | 용도 |
|---|---|---|---|
| A | 0 | 0 - 127 | 대규모 |
| B | 10 | **128 - 191** | 중규모 |
| C | **110** | **192 - 223** | 소규모 |
| D | 1110 | 224 - 239 | 멀티캐스트 |

- **루프백**은 **127.0.0.1**이고 A 클래스 대역에 속합니다.
- **사설 IP**: `10.x.x.x`, `172.16.x.x`부터 `172.31.x.x`, `192.168.x.x`. 그 밖은 **공인 IP**입니다(예: 165.141.105.240).
- C 클래스의 사설 대역 `192.168.0.0`부터 `192.168.255.0`까지에는 **네트워크가 256개** 있습니다.
- `192.168.1.0`처럼 호스트 부분이 모두 0이면 **네트워크 주소**, 모두 1이면 **브로드캐스트 주소**입니다.

### 서브넷 계산 방법

| 마스크 | 접두사 | 블록 크기 | 서브넷 개수(C 클래스) | 호스트 수/서브넷 |
|---|---|---|---|---|
| 255.255.255.128 | /25 | 128 | 2 | 126 |
| **255.255.255.192** | **/26** | **64** | **4** | **62** |
| 255.255.255.224 | /27 | 32 | 8 | 30 |

`/26`(마스크 192)이면 마지막 옥텟을 **0-63, 64-127, 128-191, 192-255** 네 블록으로 나눕니다. 주어진 IP가 속한 블록에서 다음을 얻습니다.

- 블록의 **첫 값 = 네트워크 주소**
- 블록의 **마지막 값 = 브로드캐스트 주소**
- 첫 값 + 1 = 첫 번째 사용 가능 주소(게이트웨이로 흔히 씀), 마지막 값 - 1 = 마지막 사용 가능 주소

예제입니다.

| IP / 마스크 | 속한 블록 | 네트워크 | 브로드캐스트 | 게이트웨이(첫 사용 주소) |
|---|---|---|---|---|
| 192.168.3.157 / 192 | 128-191 | 192.168.3.128 | **192.168.3.191** | |
| 192.168.3.129 / 192 | 128-191 | | **192.168.3.191** | |
| 192.168.5.189 / 26 | 128-191 | | **192.168.5.191** | |
| 192.168.3.194 / 26 | 192-255 | **192.168.3.192** | | |
| 192.168.5.150 / 192 | 128-191 | | | **192.168.5.129** |

C 클래스에 `/26`을 쓰면 서브넷이 4개이고, 서브넷마다 사용 가능한 주소가 62개이므로 **전체 사용 가능 IP는 4×62 = 248개**입니다. `/16`은 255.255.0.0, `/24`는 255.255.255.0입니다.

## 5. IPv6

| 항목 | 내용 |
|---|---|
| 주소 길이 | **128비트** |
| 특징 | 패킷 크기 확장, **흐름 제어** 지원, **인증·보안** 기능, **호스트 주소 자동 설정** |
| 틀린 설명 | "IP 주소 대역 **클래스의 확장**"(IPv6에는 클래스가 없음), "헤더 구조가 복잡해졌다"(오히려 단순화) |

## 6. LAN, MAN, WAN과 표준 기관

| 구분 | 범위·특징 |
|---|---|
| LAN | 건물·캠퍼스 내부 |
| **MAN** | 도시 규모. **IEEE 802.6, DQDB**. DSL 전화망, 케이블 TV 네트워크 인터넷이 예 |
| **WAN** | 국가·대륙. 거리 제한이 없지만 속도가 느리고 에러율이 높음. 전용회선과 교환회선 방식 |
| SAN | 스토리지 전용망(**이더넷 LAN과는 거리가 먼 장치: SAN 스위치**) |

| 기관 | 하는 일 |
|---|---|
| **ISO** | **OSI 참조 모델** 제정 |
| **IEEE** | **LAN·MAN 표준**(802 시리즈) |
| **EIA** | RS-232C, **LAN용 트위스트 페어 케이블 규격** |
| **ICANN** | **IP 주소·도메인 관리**(초기에는 미국 상무부 산하의 **IANA**가 관리, 현재는 ICANN) |

최상위 도메인은 `com`, `net`, `org`, `mil`, `kr`처럼 국가·기관 구분입니다. `go`, `or`는 `go.kr`, `or.kr`처럼 둘째 단계라서 **최상위 도메인이 아닙니다**.

## 7. LAN 구성 방식(토폴로지)

| 방식 | 특징 |
|---|---|
| **스타(성형)** | 중앙 제어기에 **점대점**으로 연결. 중앙 고장이면 **전체 중단**, 설치 비용이 많이 듦 |
| **링** | **충돌이 없고** 노드가 늘어도 성능 저하가 적음. **노드 추가가 어렵고** 한 노드의 문제로 전체가 중단될 수 있음 |
| **버스** | 하나의 통신회선을 공유, 모든 장치가 경쟁 |
| **망(Mesh)** | **장애가 나도 다른 시스템에 영향이 적고** 우회 경로가 있어 **신뢰성이 가장 높음**. 설치 비용이 많고 운영이 어려우며 고장 지점을 찾기 어려움. 백본망 구성에 주로 사용 |

## 8. 전송 기술

| 이름 | 설명 |
|---|---|
| **이더넷(Ethernet)** | **CSMA/CD**(반송파 감지 다중 접속과 충돌 탐지) 사용. 각 기기는 **48비트** MAC 주소를 가짐. BNC, UTP 케이블과 허브·스위치 사용 |
| CSMA/CD | 단말이 전송로의 **신호 유무를 조사**하고 다른 단말이 신호를 내는지 확인 |
| **FDDI** | **광섬유**, **링 구조**, **토큰 패싱**, 최대 100Mbps. 1982년 ANSI X3 위원회에서 표준화 후 ISO 규격 |
| **DQDB** | IEEE 802.6, **MAN** |
| 패킷 교환 | **패킷마다 오버헤드(헤더) 비트가 있고** 고정 대역을 할당하지 않아 이론상 무제한 수용. 회선 교환보다 **지연이 적다는 설명은 틀림** |

## 9. 케이블

| 케이블 | 설명 |
|---|---|
| **UTP** | 비차폐 꼬임쌍선. 외피를 벗기면 꼬인 쌍이 풀려 보임 |
| **STP** | 차폐 꼬임쌍선 |
| **BNC** | 양 끝에 BNC 커넥터가 달린 **동축 케이블** |
| **UTP CAT-5e** | **대역폭 100MHz, 최대 1Gbps** |
| 광케이블 | 광섬유 |

허브와 PC를 잇는 일반(다이렉트) 케이블의 배열은 **흰주, 주, 흰녹, 파, 흰파, 녹, 흰갈, 갈**입니다.

## 10. 시험 직전 점검

> - 세션 계층은 "응용 프로그램 간 통신 관리", 표현 계층은 "암호화·압축"입니다.
> - 전송 단위는 bit(물리), frame(데이터링크), packet(네트워크), segment(전송)입니다.
> - `/26`은 블록 64, 서브넷 4개, 서브넷당 호스트 62개입니다.
> - Telnet 23, SSH 22, SNMP 161, POP3 110, IMAP 143.
> - 클래스는 B가 128-191(10), C가 192-223(110)입니다.
> - 망형이 신뢰성이 가장 높고, 스타형은 중앙이 고장나면 전체가 중단됩니다.
> - 표준 기관: OSI는 ISO, LAN은 IEEE, 케이블 규격은 EIA, IP·도메인은 ICANN입니다.

## 11. OX 점검

| 문장 | 답 | 이유 |
|---|---|---|
| UDP는 3-way handshaking을 한다. | X | TCP가 합니다. |
| 루프백 주소 127.0.0.1은 B 클래스이다. | X | A 클래스 대역입니다. |
| `/26` 마스크는 255.255.255.192이다. | O | 블록 크기 64입니다. |
| SSH의 포트는 23번이다. | X | 22번입니다(23은 Telnet). |
| IPv6는 128비트 주소를 쓴다. | O | |
| 링형 LAN은 노드 추가가 쉽다. | X | 어렵습니다. |
| 세션 계층은 데이터의 암호화를 담당한다. | X | 표현 계층입니다. |
| ARP는 IP 주소를 MAC 주소로 변환한다. | O | |
