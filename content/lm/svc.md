# 인터넷 서비스 (ssh·ftp·samba)

<div class="summary">

- **SSH**는 패킷을 **암호화**한 원격 로그인·원격 셸·`scp`·`sftp`를 제공합니다(포트 22). **Telnet**은 **평문**이라 보안상 거의 쓰지 않습니다(포트 23).
- **FTP**는 **20번 포트로 데이터**, **21번 포트로 제어**를 합니다. 올리기는 **`put`**, 내려받기는 **`get`**, 진행 표시는 **`hash`**입니다.
- **SMTP**는 메일 서버끼리 주고받는 프로토콜, **POP3·IMAP**은 사용자가 메일을 받아 가는 프로토콜입니다.
- **파일 공유**: 리눅스끼리는 **NFS**, 리눅스와 윈도는 **SAMBA**입니다. **IRC**는 실시간 채팅입니다.
- **브라우저**: 모질라 재단의 Gecko는 **파이어폭스**, 구글의 Blink는 **크롬**, 콘솔용은 **lynx·links**입니다.

</div>

## 1. SSH와 Telnet

| | SSH | Telnet |
|---|---|---|
| 암호화 | **패킷 암호화** | **평문** 전송 |
| 기본 포트 | 22 | 23 |
| 지원 기능 | 원격 로그인, **원격 셸**, **원격 복사(scp)**, **안전한 파일 전송(sftp)** | 원격 접속(아이디·패스워드 사용) |
| 서버 패키지(CentOS 7) | openssh-server | **`telnet-server`** |

SSH 관련 도구는 `ssh`, `scp`, `sftp`, `rsh`(구형 원격 셸)입니다. `nfs`는 SSH와 관련이 없고, `sccp`는 존재하지 않는 도구입니다.

### 접속 형식

```
$ ssh 192.168.12.22 -p 8080          ← 포트가 8080으로 바뀐 서버 (소문자 -p)
$ ssh -l kaitman 192.168.5.13        ← 계정을 지정 (-l)
$ ssh kaitman@192.168.5.13           ← 같은 뜻의 다른 형식
$ telnet -l kaitman 192.168.5.13     ← telnet에서 계정 지정은 -l
```

| 옵션 | 뜻 |
|---|---|
| **`-p`** | ssh의 **포트 번호** 지정 (대문자 `-P`는 scp에서 쓰는 형태) |
| **`-l`** | **로그인 사용자** 지정 (ssh, telnet 공통) |
| `-n` | 표준 입력을 `/dev/null`로 보냄 |
| `-x` | X11 포워딩 해제 |

> **함정** 포트는 `ssh 주소 8080`이나 `ssh 주소:8080`이 아니라 **`-p 8080`**입니다. 계정을 바꿔 접속하는 옵션은 ssh도 telnet도 **`-l`**입니다.

### 서비스 점검

`telnet 주소 포트`로 포트가 열렸는지 점검합니다.

| 점검 대상 | 명령 |
|---|---|
| https 서비스 | `telnet www.kait.or.kr 443` |
| sftp(ssh) 서비스 | `telnet www.kait.or.kr 22` |

> **함정** `주소@포트`, `주소:포트` 형식은 틀립니다. sftp는 SSH 위에서 동작하므로 점검 포트는 21(ftp)이 아니라 **22**입니다.

## 2. FTP

| 항목 | 내용 |
|---|---|
| 포트 | **20번 = 데이터 전송**, **21번 = 제어** |
| 모드 | **Active**와 **Passive** 모두 지원 |
| 접속 | 익명 계정(**Anonymous**)으로 접속 가능, FTP 서버가 반드시 필요 |

| FTP 명령 | 하는 일 |
|---|---|
| **`put`** | 로컬 파일을 서버에 **업로드** |
| **`get`** | 서버 파일을 로컬로 **다운로드** |
| **`hash`** | 전송 진행 상태를 `#` 기호로 표시 |
| `open` / `close` | 연결 열기 / 닫기 |
| `mkdir` / `rmdir` | 디렉터리 만들기 / 삭제 |

> **함정** 올릴 때 `put`, 내려받을 때 `get`입니다. 둘의 순서를 바꾼 보기가 자주 나옵니다. `send`, `recv`, `sharp`, `bi`는 `#` 표시나 전송 명령으로 쓰이지 않습니다.

> **함정** "1984년 썬 마이크로시스템즈에서 개발한 프로토콜"은 FTP가 아니라 **NFS**의 설명입니다.

## 3. 메일 프로토콜

| 프로토콜 | 역할 |
|---|---|
| **SMTP** | **메일 서버 간의 메시지 교환**, 메일 보내기 (포트 25) |
| **POP3** | 서버의 메일을 사용자 쪽으로 가져옴 (포트 110) |
| **IMAP** | 서버에 메일을 둔 채 열람 (포트 143) |

FTP는 메일 프로토콜이 아니고 **SNMP**는 네트워크 관리용이라 메일과 가장 거리가 멉니다.

## 4. 파일 공유와 기타 서비스

| 서비스 | 설명 |
|---|---|
| **NFS** | 한 대의 리눅스에 공유 디렉터리를 만들고 **다른 리눅스(유닉스) 사용자**가 접근. 1984년 썬 마이크로시스템즈 개발 |
| **SAMBA** | 리눅스·유닉스와 **윈도 간**의 자료와 **하드웨어(프린터) 공유** |
| **IRC** | **실시간 채팅**. 여러 사용자가 모여 대화, 개인 간 대화와 파일 전송. Xchat 같은 클라이언트 사용 |
| NIS | 계정 정보를 중앙에서 공유하는 서비스 |
| Usenet | 뉴스그룹 게시판 |
| Gopher | 문서 계층 검색 서비스 |

## 5. 웹과 브라우저

| 개념 | 설명 |
|---|---|
| **WWW** | 웹페이지와 웹페이지를 연결하는 **하이퍼텍스트** 방식의 정보검색 시스템 |
| **URL** | 웹 서버의 자원에 접근하기 위한 주소 |
| HTML | 웹 문서를 만드는 마크업 언어 (하이퍼텍스트 방식 자체가 아님) |

| 브라우저 | 특징 |
|---|---|
| **파이어폭스** | 모질라(Mozilla) 재단의 자유 소프트웨어, **게코(Gecko)** 엔진, 탭 브라우징·맞춤법 검사·통합 검색 |
| **크롬** | 구글 개발, 처음엔 웹키트, 현재는 웹키트에서 갈라진 **블링크(Blink)** |
| **lynx, links** | X 윈도가 없는 **콘솔 창**용 텍스트 브라우저 |
| 사파리, 오페라, 엣지 | GUI 환경에서 쓰는 브라우저 |

## 6. 부팅 모드 (이 장에서 함께 묻는 내용)

텍스트(콘솔) 모드로 부팅하려면 **`systemctl set-default multi-user.target`**입니다. 끝이 `.service`가 아니라 `.target`이고, `get-default`는 설정이 아니라 확인용입니다.

## 7. 시험 직전 점검

> - ssh 포트는 `-p`, 계정은 `-l`. telnet도 계정은 `-l`.
> - FTP는 20 데이터, 21 제어. 올리기 `put`, 내려받기 `get`, `#` 표시 `hash`.
> - 메일 서버 간 교환은 SMTP.
> - 윈도와 공유는 SAMBA, 리눅스끼리는 NFS, 채팅은 IRC.
> - Gecko는 파이어폭스, Blink는 크롬, 콘솔은 lynx·links.
> - 텔넷 서버 패키지는 `telnet-server`.

## 8. OX 점검

| 문장 | 답 | 이유 |
|---|---|---|
| SSH는 평문으로 데이터를 전송한다. | X | 암호화합니다. 평문은 Telnet입니다. |
| ssh로 포트를 지정할 때 `-p`를 쓴다. | O | |
| FTP의 20번 포트는 제어, 21번은 데이터이다. | X | 반대입니다. 20은 데이터, 21은 제어입니다. |
| `put`은 서버에서 로컬로 파일을 가져온다. | X | 업로드입니다. 가져오기는 `get`입니다. |
| POP3는 메일 서버 간 교환 프로토콜이다. | X | SMTP입니다. |
| SAMBA로 윈도 사용자가 리눅스에 연결된 프린터를 쓸 수 있다. | O | |
| `lynx`는 콘솔용 웹 브라우저이다. | O | |
| `systemctl get-default multi-user.target`으로 텍스트 모드 부팅을 설정한다. | X | 설정은 `set-default`입니다. |
