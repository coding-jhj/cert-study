# 에디터 (vi·nano·emacs)

<div class="summary">

- **누가 만들었나**: vi는 빌 조이(1976), vim은 브람 무레나르, emacs는 리처드 스톨먼(GNU), pico는 워싱턴 대학, nano는 pico의 GNU 복제판입니다.
- **X 윈도 없이 쓰는 터미널 편집기**는 vi, vim, nano, pico, emacs입니다. **X 윈도가 필요한 편집기**는 gedit(GNOME)와 kwrite(KDE)입니다.
- **vi**는 세 모드(명령, 입력, ex)를 오갑니다. 저장하고 종료는 `:wq`, 저장 없이 종료는 `:q!`입니다.
- **치환**은 `:% s/찾을것/바꿀것/g`이고 `^`는 줄 시작, `$`는 줄 끝, `\<`와 `\>`는 단어의 시작과 끝입니다.
- **설정 저장 파일**은 vi가 `~/.exrc`, vim이 `~/.vimrc`입니다.

</div>

## 1. 에디터 비교

| 편집기 | 만든 곳 | 특징 |
|---|---|---|
| vi | 1976년, 빌 조이 | 유닉스 계열의 대표 편집기. **가장 먼저 등장** |
| vim (vi improved) | 브람 무레나르 | vi를 개선 |
| emacs | 리처드 스톨먼(GNU 프로젝트) | 고성능 문서 편집기를 넘어 텍스트 처리를 위한 **통합 환경**. (고슬링 이맥스와의 관계로 제임스 고슬링도 거론됩니다) |
| pico | 워싱턴 대학 | 윈도 메모장처럼 간편함. 라이선스 문제로 대체됨 |
| nano | GNU 프로젝트 | **pico의 복제판**. 기본 사용법이 pico와 같음 |
| gedit | GNOME | **X 윈도 환경에서만** 실행되는 GUI 편집기 |
| kwrite | KDE | X 윈도 환경에서만 사용 가능한 GUI 편집기 |

X 윈도를 설치하지 않은 서버에서도 nano, vim, emacs(터미널 모드)는 쓸 수 있지만 gedit과 kwrite는 쓸 수 없습니다. 기본 사용법이 같은 조합은 **pico와 nano**입니다.

## 2. nano와 emacs 단축키

| 편집기 | 키 | 동작 |
|---|---|---|
| nano | `Ctrl+x` | 종료 |
| nano | `Ctrl+a` | 줄의 **처음**으로 이동 |
| nano | `Ctrl+e` | 줄의 **끝**으로 이동 |
| emacs | `Ctrl+x` 다음 `Ctrl+c` | **종료** (순서 중요) |

## 3. vi의 세 가지 모드

| 모드 | 들어가는 법 | 하는 일 |
|---|---|---|
| 명령 모드 | 시작할 때, `Esc` | 이동, 삭제, 복사, 붙이기 |
| 입력 모드 | 명령 모드에서 `a`, `i`, `o` 등 | 글자 입력 |
| ex 모드 | 명령 모드에서 `:` | 저장·종료·치환·환경 설정 |

**입력 모드로 전환하는 키**는 `a`(커서 뒤), `i`(커서 앞), `o`(아래에 새 줄) 등이고 **`e`는 아닙니다**(`e`는 단어 끝으로 이동).

### 명령 모드 키

| 키 | 동작 |
|---|---|
| `h` `j` `k` `l` | 왼쪽·**아래**·위·오른쪽 이동(방향키가 없을 때) |
| `x` | 커서 위치의 **글자 하나** 삭제 |
| `dd` | **한 줄** 삭제 |
| `yy`, `3yy` | 한 줄 복사, **3줄 복사** |
| `p` | 붙이기 |
| `u` | 방금 한 동작을 되돌리기(직전에 삭제한 줄 복원) |
| `ZZ` | 저장하고 종료 |
| `/문자열` | 아래로 검색, `n`은 다음 결과, `N`은 반대 방향 |
| `?문자열` | 위로 검색 |

### ex 모드 명령

| 명령 | 동작 |
|---|---|
| `:w` | 저장 |
| `:w 파일명` | 지정한 파일명으로 저장 |
| `:wq`, `:x` | 저장하고 종료 |
| `:q` | 종료(수정 사항이 있으면 거부) |
| `:q!` | **저장하지 않고 강제 종료** |
| `:$` | 문서의 마지막 줄로 이동 |

> **함정** `:q`는 "무조건 종료"가 아닙니다. 수정 사항이 있으면 경고하고 종료하지 않습니다. 무조건 종료는 `:q!`입니다.

### 실행 옵션

| 명령 | 동작 |
|---|---|
| `vi +파일` | 파일을 열고 커서를 **마지막 줄**에 둠(`vi + line.txt`) |
| `vi -r` | 비정상 종료로 남은 **스왑 파일 목록** 확인·복구 |
| `vi -R` | 읽기 전용으로 열기 |

## 4. vi 환경 설정(`:set`)

| 설정 | 의미 |
|---|---|
| `set nu` (`set number`) | 각 행 앞에 **행 번호** 표시. 끄는 것은 `set nonu` |
| `set ai` (autoindent) | 줄을 바꿨을 때 **윗줄과 같은 열**에 커서를 맞춤(들여쓰기 유지). C 프로그래밍에 유용 |
| `set ic` | 검색 때 대소문자 무시 |
| `set sm` | 괄호를 닫을 때 짝이 되는 괄호를 잠깐 표시 |
| `set list` | 개행 문자(`$`), 탭(`^I`) 등 **보이지 않는 문자**를 표시 |

`set` 설정은 편집기를 끄면 사라집니다. **계속 쓰려면** vi는 홈 디렉터리의 **`.exrc`**, vim은 **`.vimrc`**에 적어 둡니다.

```
$ cat > ~/.exrc
set nu
(Ctrl+d로 입력 종료)
```

## 5. vi 치환

문법은 `:범위 s/찾을문자열/바꿀문자열/옵션`입니다. `%`는 **파일 전체**, `g`는 **한 줄 안의 모든** 일치를 뜻합니다.

| 정규식 기호 | 의미 |
|---|---|
| `^` | 줄의 시작 |
| `$` | 줄의 끝 |
| `\<` | 단어의 시작 |
| `\>` | 단어의 끝 |

| 하려는 일 | 명령 |
|---|---|
| 모든 windows를 linux로 | `:% s/windows/linux/g` |
| 줄이 linux로 끝나면 끝에 `.` 붙이기 | `:% s/linux$/linux./` |
| 줄이 linux로 **시작**하면 Linux로 | `:% s/^linux/Linux/` |
| 줄 전체가 linux일 때만 | `:% s/^linux$/Linux/g` |
| 단어가 linux로 **시작**하는 경우 | `:% s/\<linux/Linux/g` |
| 정확히 ihd라는 **단어**만 kait로 | `:% s/\<ihd\>/kait/g` |

찾을 문자열과 바꿀 문자열을 거꾸로 쓰지 않도록 주의합니다. `s/A/B/`는 **A를 B로** 바꿉니다.

## 6. 시험 직전 점검

> - vi 개발자는 빌 조이(1976), vim은 브람 무레나르, emacs는 리처드 스톨먼입니다.
> - 서버에서 못 쓰는 편집기는 gedit과 kwrite입니다.
> - `:q!`는 저장 없이 종료, `:wq`는 저장 후 종료, `:w 파일명`은 다른 이름으로 저장입니다.
> - `set ai`는 윗줄 들여쓰기 유지, `set nu`는 행 번호, `set list`는 보이지 않는 문자 표시입니다.
> - 설정 저장 파일은 vi는 `.exrc`, vim은 `.vimrc`입니다.
> - 치환에서 `^`는 시작, `$`는 끝, `\<`는 단어 시작입니다.

## 7. OX 점검

| 문장 | 답 | 이유 |
|---|---|---|
| vi에서 `:q`는 수정 사항이 있어도 무조건 종료한다. | X | 무조건 종료는 `:q!`입니다. |
| nano는 pico를 대체하려고 만든 GNU 편집기이다. | O | |
| emacs는 `Ctrl+x`, `Ctrl+c`로 종료한다. | O | |
| gedit은 X 윈도 없이도 실행된다. | X | GUI 환경이 필요합니다. |
| vi 명령 모드에서 `x`는 커서 위치의 글자를 지운다. | O | 한 줄 삭제는 `dd`입니다. |
| `vi + file`은 파일을 마지막 줄부터 연다. | O | |
| `set nu`로 켠 설정은 편집기를 닫아도 계속 유지된다. | X | `.exrc`나 `.vimrc`에 적어야 합니다. |
| `:% s/\<ihd\>/kait/g`는 ihd라는 단어만 kait로 바꾼다. | O | |
