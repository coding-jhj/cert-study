# 리눅스 시스템 관리 명령

<div class="summary">

- **디렉터리**: 설정과 계정 정보 `/etc`, 가상 파일시스템(프로세스·하드웨어 정보) `/proc`, 로그와 메일 `/var`, 부팅 커널 `/boot`, 임시 파일 `/tmp`. **`/usr`는 사용자 계정 위치가 아닙니다**(계정 홈은 `/home`).
- **권한**: 숫자 모드는 r=4, w=2, x=1. `-rwxr-x--x`는 `751`. 소유자 변경은 **`chown`** 입니다(root 전용).
- **프로세스**: 확인 `ps`, 실시간 `top`, 종료 `kill`, 우선순위 `nice`, 트리 `pstree`. **열린 포트**는 `netstat`(또는 `ss`).
- **예약 작업**: `crontab`의 필드는 `분 시 일 월 요일`. 삭제는 `crontab -r`.
- **종료와 재부팅**: `init 0`/`halt`/`poweroff`/`shutdown -h now`는 종료, **`init 6`** 은 재부팅. 런레벨 5가 다중 사용자 + GUI입니다.

</div>

## 1. 디렉터리 구조

| 디렉터리 | 내용 |
|---|---|
| **`/etc`** | **환경설정과 사용자 정보**(passwd 등), 부팅 시 마운트 정보 `/etc/fstab` |
| **`/proc`** | **가상 파일시스템**. 동작 중인 프로세스 상태, 하드웨어, 시스템 정보 |
| **`/var`** | 시스템 **로그 파일과 메일** |
| **`/boot`** | 부팅 가능한 커널 이미지 |
| `/tmp` | 임시 파일 |
| `/home` | 일반 사용자의 홈 디렉터리 |
| `/root` | root의 홈 디렉터리 |
| `/bin`, `/sbin`, `/lib` | 기본 명령, 시스템 관리 명령, 라이브러리 |
| `/usr` | 프로그램과 공유 자료 (**사용자 계정이 위치하는 곳이 아님**) |

**홈 디렉터리**는 사용자에게 할당되어 사용자가 자유롭게 쓰는 영역이고, 현재 위치와 관계없이 자신의 홈 디렉터리로 이동하는 명령은 `cd ~`입니다.

### 로그 파일

| 파일 | 내용 |
|---|---|
| **`/var/log/dmesg`** | **부팅할 때의 커널 메시지**. 하드웨어, 디스크, 메모리, CPU, 커널 이상 확인 |
| `/var/log/lastlog` | 마지막 로그인 기록 |
| `/var/log/btmp` | 로그인 실패 기록 (`lastb`로 확인) |
| `/var/log/cron` | cron 실행 기록 |

비인가자의 로그인 시도 이력은 **`lastb`** 로 확인합니다. `history`는 명령 이력입니다.

### `/etc/passwd` 한 줄 읽기

```
user1:x:500:500::/home/user1:/bin/bash
```

| 필드 | 값 |
|---|---|
| 계정 ID | `user1` |
| 패스워드 | `x` (실제 암호는 별도 파일에 있음, 패스워드가 'x'라는 설명은 틀림) |
| UID : GID | 500 : 500 |
| 홈 디렉터리 | `/home/user1` |
| 기본 셸 | `/bin/bash` |

## 2. 파일 타입과 권한

`ls -al` 맨 앞 글자: `-` **일반 파일**, `d` 디렉터리, `l` 링크, `b`/`c` 장치 파일. 이어서 소유자, 그룹, 기타 사용자의 권한이 3글자씩 옵니다.

| 숫자 | 권한 |
|---|---|
| 7 | rwx |
| 6 | rw- |
| 5 | r-x |
| 4 | r-- |
| 1 | --x |

`-rwxr-x--x` = 소유자 rwx(7), 그룹 r-x(5), 기타 --x(1) → **751**. 그룹은 읽기와 실행, 기타는 실행만 가집니다.

### chmod 문제

| 요구 | 명령 |
|---|---|
| 원래 `rw-r--r--`에 **모든 사용자 쓰기 추가** | `chmod a+w` = `chmod ugo+w` (결과 `rw-rw-rw-` = 666) |
| 위와 **결과가 다른 것** | `chmod go=w` (그룹·기타를 쓰기 전용으로 **덮어씀**) |
| 소유자와 그룹은 rwx, 그 외는 읽기만 | `chmod 774` |
| 소유자 rw, 그 외는 읽기만 | `chmod 644` |
| 모든 사용자 쓰기 금지 | `chmod a-w` |
| 디렉터리와 하위 전체에 소유자 rwx, 그룹·기타 r-x | `chmod -R 755 /var/www/upload` (`-R`이 하위까지 적용) |

| 명령 | 기능 |
|---|---|
| **`chown`** | 파일·디렉터리의 **소유자와 소유 그룹 변경** (root만 사용 가능) |
| chmod | 권한 변경 |
| useradd | 사용자 추가 |
| chage | 암호 만료 정책 |
| `pwd`, `ls`, `rm` | 일반 사용자도 사용 |

> **함정** `=`는 지정한 대상의 권한을 통째로 바꾸고 `+`/`-`는 더하거나 뺍니다. `go=w`는 원래 있던 읽기 권한을 지우므로 `a+w`와 결과가 다릅니다.

### 사용자와 암호 정책

```
# useradd -g icqa network               ← 이름 network, 기본 그룹 icqa (-g는 기본 그룹)
$ sudo chage -m 2 -M 100 -W 10 -I 10 -E 2026-12-25 John
```

| chage 옵션 | 뜻 |
|---|---|
| `-m` | 암호 최소 사용 일수 |
| `-M` | 암호 최대 사용 일수 |
| **`-W`** | **만료 전 경고 일수** (10일 전 경고 = `-W 10`) |
| `-I` | 만료 후 비활성화 유예 일수 |
| `-E` | 계정 만료일 |

> **함정** `useradd -g 그룹 사용자` 순서입니다. `-g network icqa`처럼 이름이 뒤바뀌면 틀립니다.

## 3. 파일 검색과 편집

**find**: `-name` 파일 이름(사용자 이름이 아님), `-type` 파일 형식(f, d 등), `-perm` 권한, **`-exec`** 찾은 파일에 삭제 같은 명령을 실행.

**리다이렉션**

| 기호 | 동작 |
|---|---|
| `>` | 결과를 파일에 **쓰기(덮어쓰기)** |
| `>>` | **추가(append)** |
| `<` | 파일을 입력으로 |
| `<<` | here document |

`ls -al > output.txt`는 덮어씁니다. 페이지 단위로 보려면 `cat exam.txt | more`입니다.

**mv -i file1 file2**: file2가 이미 있으면 **덮어쓸지 물어봅니다**.

**vi 편집기**

| 명령 | 동작 |
|---|---|
| `:10,20s/old/new/g` | 10행에서 20행까지 **한 행의 모든** old를 new로 (`g` 없으면 행마다 첫 번째만) |
| `x` | 문자 **하나** 삭제 |
| `dd` | 한 줄 삭제 |
| `dw` | 단어 삭제 |
| `D` | 커서부터 줄 끝까지 삭제 |
| `:wq`, `:wq!`, `:q!` | 저장 후 종료, 강제 저장 종료, 저장하지 않고 강제 종료 |
| `:q` | 변경 내용이 있으면 **바로 종료되지 않음** |

## 4. 프로세스, 메모리, 포트

| 명령 | 기능 |
|---|---|
| **`ps -ef`** | UID, PID, PPID, 시작 시각, 명령을 보여 줌. **데몬이 살아 있는지** 확인 |
| **`top`** | 프로세스 상태와 시스템 사용량을 **실시간** 모니터링 (가장 우선순위가 높은 프로세스를 보여 주는 명령이 아님) |
| `kill` | 프로세스 종료 (`kill PID`) |
| `nice` | 우선순위 변경 |
| `pstree` | 트리 형태로 표시 |
| **`free`** | 사용 중·사용 가능한 **메모리**, 공유 메모리, 가상 메모리 정보 |
| `du` | 디렉터리 사용량 |
| `df` | 파일시스템의 사용 가능한 양 |
| **`netstat`** | 열린 포트와 연결 정보. `-a` 모든 연결과 대기 포트, **`-t` TCP**, `-r` 라우팅, `-p` PID와 프로그램명, `-n` 숫자 |
| `netstat -antp` | 불필요하게 열린 서비스 포트 확인 |
| `lsattr` | 파일 속성 확인 (`i` 속성이 있으면 삭제·수정 불가) |

`ps -ef | grep python`은 파이썬 프로세스의 **PID, 부모 PID(PPID), 시작 시간, 명령**을 보여 줍니다.

**ps 출력 읽기**: 열 순서는 `UID PID PPID C STIME TTY TIME CMD`입니다. `icqa 1869 1868 ...`이면 PID는 1869이고 **PPID는 1868**입니다. 다섯 번째 프로세스(PID 1902)를 종료하는 명령은 `kill 1902`입니다.

> **함정** `netstat -t`는 TCP 연결만 보여 주는 옵션입니다. "연결된 이후 시간"을 표시하는 옵션이 아닙니다.

> **함정** 데몬은 **백그라운드**로 실행되는 시스템 서비스 프로세스이며 `ps afx`로 확인할 수 있습니다. 부팅 때만 시작할 수 있는 것은 아닙니다.

### ping 결과 읽기

```
64 bytes from 210.103.175.224: icmp_seq=1 ttl=54 time=7.45 ms
rtt min/avg/max/mdev = 7.085/7.237/7.450/0.155 ms
```

최단 시간은 **7.085ms**, **평균은 7.237ms**, 최대가 7.450ms입니다. "평균이 7.450ms"는 틀립니다. 3개를 보내 3개를 받았고 손실은 0%입니다.

Linux의 `ping`은 중단할 때까지 반복합니다(`-c 3`으로 횟수 제한). 윈도에서 중단 전까지 반복하는 옵션은 **`ping -t`** 입니다(`-a` 주소 확인, `-f` 단편화 금지, `-n` 횟수). 윈도의 **`pathping`** 은 `tracert`와 같은 정보를 보여 주면서 홉 사이 시간 정보를 출력이 끝날 때까지 모아 줍니다.

## 5. 디스크, 파티션, 스왑

| 명령 / 파일 | 기능 |
|---|---|
| `fdisk` | 파티션 설정 (MBR) |
| **`gdisk`** | **2TB 이상** 디스크를 **GPT**로 파티셔닝 |
| `mkfs` | **파일시스템 생성** |
| `fsck` | 파일시스템 점검 |
| `mount` | 외부 장치를 디렉터리에 연결 |
| **`/etc/fstab`** | **부팅과 함께 자동으로 마운트**할 항목과 옵션 |

새 디스크를 쓰려면 fdisk → mkfs → mount 순입니다. `cal`은 달력이라 관계가 가장 적습니다.

> **함정** `fdisk`는 파티션 도구이고 파일시스템 점검은 `fsck`입니다.

**`/dev/sda5`**: `sd`는 SATA/SCSI 디스크 인터페이스, `a`는 **첫 번째 디스크**, `5`는 그 디스크의 **다섯 번째 파티션**(논리 파티션)입니다. "다섯 번째로 연결된 물리 디스크"는 틀립니다. 장치를 파일 형식으로 나타냅니다.

**SWAP**: RAM이 부족할 때 하드디스크의 일부를 메모리처럼 쓰는 파티션입니다. 보통 실제 메모리의 두 배 정도가 적당하다고 보며, 스왑이 자주 일어나면 메모리를 증설해야 합니다. 한 번 설정해도 **나중에 추가할 수 있습니다**.

## 6. 부팅, 종료, 서비스

| 명령 | 동작 |
|---|---|
| `init 0` | 종료 |
| `init 1` | 단일 사용자 모드 |
| `init 3` | 다중 사용자 텍스트 모드 |
| **`init 5` (런레벨 5)** | **다중 사용자 + GUI** |
| **`init 6`** | **재부팅** |
| `shutdown -h now`, `poweroff`, `halt` | 종료 (init 6은 종료 명령이 아님) |

**GRUB**: 리눅스 부트 로더로, 다른 운영체제와의 **멀티 부팅**을 지원합니다. MBR은 부트 섹터 영역입니다.

**Shell**: 사용자가 내린 명령을 해석해 **Kernel에 전달**하는 명령어 해석기입니다.

**systemctl** (systemd, RHEL 계열): `systemctl start httpd`, `systemctl enable sshd`, `systemctl status nginx`는 올바른 사용 예입니다. `systemctl passwd root`는 없는 사용법입니다.

## 7. crontab

```
분  시  일  월  요일  명령
0   10  *   *   1     /etc/check.sh      ← 매주 월요일 오전 10시
```

| 필드 | 값 |
|---|---|
| 분 | 0-59 |
| 시 | 0-23 |
| 요일 | 0 또는 7이 일요일, **1이 월요일** |

| 옵션 | 기능 |
|---|---|
| `crontab -e` | 편집 |
| `crontab -l` | 목록 |
| **`crontab -r`** | **삭제** |
| `crontab -u` | 사용자 지정 |

> **함정** `10 0 * * 1`은 월요일 0시 10분입니다. 분이 앞, 시가 뒤입니다. 요일 0은 일요일입니다.

## 8. DNS SOA 레코드(리눅스 BIND)

Zone 파일은 항상 **SOA로 시작**하고, 해당 Zone의 네임서버를 유지하는 기본 자료를 담으며, **Refresh**는 주 서버와 보조 서버의 동기 주기입니다. **TTL이 길면 캐시가 오래 유지되어 DNS 부하가 줄어듭니다**("TTL이 길면 부하가 늘어난다"는 틀림).

## 9. 시험 직전 점검

> - `/etc` 설정과 계정, `/proc` 가상 파일시스템, `/var` 로그, `/usr`는 프로그램 위치.
> - 751 = rwxr-x--x. `go=w`는 덮어쓰기라 `a+w`와 다름.
> - `chown`은 소유자 변경, `chmod`는 권한 변경.
> - 열린 포트 `netstat`, 데몬 확인 `ps`, 실시간 `top`, 메모리 `free`.
> - cron은 `분 시 일 월 요일`. 월요일 10시 = `0 10 * * 1`. 삭제는 `-r`.
> - chage 경고 일수 `-W`. 로그인 실패 `lastb`. 부팅 메시지 `dmesg`.
> - init 6 = 재부팅, 런레벨 5 = GUI. GRUB = 멀티 부팅.
> - GPT 파티셔닝은 gdisk. 파일시스템 생성은 mkfs, 점검은 fsck.
