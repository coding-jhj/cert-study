# 프린터·사운드·스캐너

<div class="summary">

- **인쇄 시스템**은 **CUPS**(애플, IPP 사용)와 **LPRng**(버클리, BSD 계열)입니다. 원격 인쇄 프로토콜은 **IPP**입니다.
- **인쇄 명령은 두 계열**입니다. **System V**는 `lp`, `lpstat`, `cancel`, `lpadmin`이고, **BSD**는 `lpr`, `lpq`, `lprm`, `lpc`입니다.
- **사운드**는 **OSS**(옛 방식)에서 **ALSA**로 바뀌었고, 제어 명령은 `alsactl`입니다.
- **스캐너**는 **SANE**(API)과 **XSANE**(GTK+ 기반 화면 프로그램)입니다.
- CentOS 7에서 X 윈도 기반 프린터 설정 명령은 **`system-config-printer`**입니다.

</div>

## 1. 인쇄 시스템

| 이름 | 설명 |
|---|---|
| **CUPS** | 애플이 개발한 공개 소프트웨어 프린팅 시스템. 유닉스·리눅스 시스템을 **프린터 서버**로 쓰게 해 줍니다. **리눅스에서 프린터 서버를 만들 때 설치하는 프로그램**입니다. |
| **LPRng** | 버클리 프린팅 시스템. BSD 계열 유닉스에서 쓰려고 개발했고 **라인 프린터 데몬(LPD)** 프로토콜을 사용하며, 프린터 스풀링과 네트워크 프린터 서버를 지원합니다. |
| **LPD** | 라인 프린터 데몬. BSD의 전통 인쇄 데몬 |
| **IPP** | Internet Printing Protocol. **인터넷에서 원격으로 인쇄**할 때 쓰는 프로토콜 |
| **PPD** | 프린터 설명 파일 |

"프린팅 시스템과 가장 거리가 먼 것"을 묻는 문제의 답은 스캐너용 **SANE**입니다.

## 2. 인쇄 명령 — System V와 BSD

| 기능 | System V 계열 | BSD 계열 |
|---|---|---|
| 인쇄 요청 | `lp` | `lpr` |
| 대기열(큐) 상태 | `lpstat` | `lpq` |
| 작업 취소 | `cancel` | `lprm` |
| 프린터 관리 | `lpadmin` | `lpc` |

```
$ lp /etc/passwd          # System V 방식으로 파일 인쇄
$ lpr /etc/passwd         # BSD 방식으로 인쇄
$ lpstat                  # 큐의 작업 정보
$ cancel 작업번호         # 예약된 인쇄 작업 취소
```

"나머지 셋과 계열이 다른 것"에서는 `lp`가 한 명이고 `lpr`, `lpq`, `lprm`이 BSD입니다. 반대로 System V에서 틀린 것을 찾을 때는 `lpc`가 BSD 명령입니다.

CentOS 7에서 X 윈도 환경에서 프린터를 설정하는 프로그램은 **`system-config-printer`**입니다. 이전 버전의 `printconf`, `printtool`, `redhat-config-printer`는 쓰지 않습니다. 실행하면 "인쇄 설정" 창에 프린터 추가 버튼이 나옵니다.

## 3. 사운드 카드

| 이름 | 설명 |
|---|---|
| **OSS** | 표준 유닉스 장치 시스템 콜(POSIX)에 기반한 **초기** 사운드 인터페이스. 처음에는 자유 소프트웨어였으나 **사유화**되었고 라이선스 옵션이 4가지입니다. |
| **ALSA** | 사운드카드를 **자동으로 구성**하고 **여러 사운드 장치를 관리**합니다. **1998년 Jaroslav Kysela가 시작**, GPL·LGPL 기반. OSS를 대체했습니다. |

- 사운드 카드의 제어·설정 명령은 **`alsactl`**입니다. 프린팅 명령이 아닙니다.
- 흐름은 "초기 리눅스에서는 **OSS**, 사유화되면서 **ALSA**로 전환"입니다.

## 4. 스캐너

| 이름 | 설명 |
|---|---|
| **SANE** | 스캐너 사용을 위한 **API**(Scanner Access Now Easy) |
| **XSANE** | X 윈도 기반 **GTK+ 라이브러리**로 만든 스캐너 프로그램. 스캔 외에 캡처한 이미지 수정도 가능 |

"스캐너를 사용하기 위해 설치해야 하는 패키지"는 XSANE이고, "스캐너 관련 API·프로그램"은 SANE입니다.

## 5. 시험 직전 점검

> - `lp`는 System V, `lpr`은 BSD입니다. `lpc`와 `lpq`, `lprm`도 BSD입니다.
> - 인쇄 대기열은 `lpstat`(System V) 또는 `lpq`(BSD), 작업 취소는 `cancel`(System V) 또는 `lprm`(BSD)입니다.
> - 사운드는 OSS → ALSA, 스캐너는 SANE/XSANE, 프린터 서버는 CUPS입니다.
> - `alsactl`은 사운드, `lpadmin`은 프린터 관리입니다.

## 6. OX 점검

| 문장 | 답 | 이유 |
|---|---|---|
| `lpr`은 System V 계열의 인쇄 명령이다. | X | BSD 계열입니다. |
| `cancel`로 예약된 인쇄 작업을 취소할 수 있다. | O | System V 명령입니다. |
| CUPS는 스캐너를 위한 프로그램이다. | X | 프린터 서버용입니다. 스캐너는 SANE입니다. |
| ALSA는 사운드카드를 자동으로 구성하게 하는 것이 목적이다. | O | |
| `alsactl`은 프린터를 제어하는 명령이다. | X | 사운드 카드를 제어합니다. |
| 인터넷에서 원격으로 인쇄할 때 쓰는 프로토콜은 IPP이다. | O | |
