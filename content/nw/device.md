# 네트워크 장비 (스위치·게이트웨이·로드밸런서)

<div class="summary">

- **장비와 계층**: 리피터·허브 = 물리, **L2 스위치 = 데이터링크(MAC 주소)**, 라우터 = 네트워크(IP 주소), **L4 스위치 = 전송(포트)**, L7 스위치 = 응용, **게이트웨이 = 서로 다른 프로토콜을 변환·연결**.
- **VLAN**: 하나의 물리 스위치를 논리적으로 나눠 **브로드캐스트 도메인을 분리**합니다. VLAN 사이 통신은 3계층 장비를 거칩니다. 스위치 간 연결은 **트렁크**, VLAN ID가 붙은 프레임은 **태그(Tagged) 포트**입니다.
- **STP**는 L2 스위치 네트워크의 **루프(브로드캐스트 폭주)** 를 막습니다.
- **로드밸런서**는 여러 서버로 요청을 분산하고 **헬스 체크**로 정상 서버로만 보냅니다. 순차 분산은 **Round Robin**입니다.
- **PXE**는 네트워크 카드로 부팅하는 기술입니다.

</div>

## 1. 장비와 OSI 계층

| 장비 | 계층 | 기준 / 기능 |
|---|---|---|
| 리피터 | 1 물리 | 약해진 신호를 **단순 증폭·재생성**해 전송 거리 연장 |
| 허브 | 1 물리 | 집선 장치 |
| **L2 스위치** | 2 데이터링크 | 프레임 전송 시 **목적지 MAC 주소**를 보고 중계 (IP, 포트, URL 주소가 아님) |
| **라우터** | 3 네트워크 (TCP/IP의 인터넷 계층) | IP 주소로 경로 선택 |
| **L4 스위치** | 4 전송 | TCP, UDP, HTTP 등의 헤더를 분석해 **부하 분산** |
| L7 스위치 | 7 응용 | IP, 포트에 더해 L5-L7 정보까지 보고 처리. L2/L3/L4 기능을 포괄할 수 있음 |
| **게이트웨이** | 여러 계층 | 전혀 다른 프로토콜의 네트워크를 연결하고 데이터 형식을 변환 |

### 게이트웨이

- 두 개의 완전히 다른 네트워크 사이의 **데이터 형식을 변환**합니다.
- **프로토콜이 다른** 네트워크 환경을 연결합니다.
- 데이터 변환을 하므로 **병목 현상**이 생길 수 있습니다.
- "OSI의 **전송 계층만** 연결하는 장비", "L2 스위치처럼 **프레임만 중계**"한다는 설명은 틀립니다.
- 트위스트 페어 집선 장치는 허브, 신호 증폭은 리피터, 물리 주소 캐시 테이블은 스위치/ARP의 설명입니다.

### L4 스위치 (로드 밸런서)

| 기본 기능 | |
|---|---|
| 서버 부하를 분산 | 외부 요청이 L4 스위치를 거쳐 각 서버로 분산 |
| **헬스 체크** | 서버 상태 확인 |
| 알고리즘 분산 | Round Robin 등 |
| **NAT** | 주소 변환 |

> **함정** L4 스위치는 **전송 계층** 장비이고 네트워크 계층 장비가 아닙니다. **애플리케이션 계층의 보안 기능**은 L4 스위치의 기본 기능이 아닙니다(L7이나 WAF의 영역). L7 스위치가 "TCP/UDP 헤더만으로 로드 밸런싱"한다는 설명은 틀립니다.

## 2. 로드 밸런싱

사용량과 처리량을 늘리고 지연율과 응답시간을 줄이며 시스템 부하를 피하게 하는 **최적화 기술**입니다. 같은 서비스를 하는 여러 서버를 등록하고 요청을 분산하며, 정상 서버로만 전달해 **장애 내성**을 높입니다.

| 분산 방식 | 설명 |
|---|---|
| **Round Robin** | 특별한 규칙 없이 **순차적으로 돌아가면서** 분산 |
| Weighted Round Robin | 서버마다 가중치를 두고 순차 분산 |
| Least Connection | 연결 수가 가장 적은 서버로 |
| Weighted Least Connection | 가중치를 둔 최소 연결 |

> **함정** 보기의 다른 설명들은 별개의 개념입니다. "물리적 망 구성과 무관한 가상 LAN"은 VLAN, "물리 컴퓨터에서 분리된 또 하나의 컴퓨터"는 가상 머신, "웹 브라우저와 서버 간 정보 암호화"는 SSL/TLS입니다.

## 3. VLAN

| 특징 | 설명 |
|---|---|
| 정의 | 물리적 케이블이 아닌 **소프트웨어**로 구성된 LAN, **물리적 망 구성과 상관없이** 가상으로 구성 |
| 효과 | 데이터링크 계층에서 **브로드캐스트 도메인을 나눔**, 스위치는 같은 그룹이 아닌 곳으로 브로드캐스트 프레임을 전달하지 않음 |
| 보안 | 서로 다른 논리 그룹에 **서로 다른 보안 정책을 적용할 수 있음**. 태그가 다른 네트워크로의 접근을 차단 |
| 통신 | 부서별로 분리된 네트워크는 **3계층 장비를 통해서만** 통신 |
| 트렁크 | 여러 스위치에 걸쳐 VLAN을 운용할 때 **스위치 간 연결 인터페이스** |
| 태그(Tagged) 포트 | VLAN ID를 프레임에 추가해 **하나의 포트로 여러 VLAN 트래픽을 전달** (VLAN마다 별도 포트를 쓰는 낭비를 막음) |

> **함정** "VLAN은 서로 다른 보안 정책을 적용할 수 없다"는 틀립니다. VLAN은 하나의 물리 스위치를 논리적으로 여러 개의 스위치처럼 쓰게 하는 기술입니다. VPN(가상 사설망), VCN, IPS와 혼동하지 않습니다. STM, ATM, ALOHA는 전송·접근 기술입니다.

## 4. STP

L2 스위치 네트워크에 **루프 구조**(복합 다중 루프)가 생기면 과도한 **브로드캐스트 트래픽**으로 네트워크를 쓸 수 없게 됩니다. 이 **다중 루프를 방지**하려고 만든 기술이 **STP(Spanning Tree Protocol)** 입니다. 포트 미러링은 트래픽 복사, Store and Forward는 스위칭 방식, Native VLAN은 태그 없는 VLAN입니다.

## 5. 기타

| 용어 | 설명 |
|---|---|
| **PXE (Pre-boot eXecution Environment)** | **네트워크 카드를 통해 컴퓨터를 부팅**할 수 있게 하는 기술 |
| PnP | 장치 자동 인식 |
| PoE | 이더넷으로 전원 공급 |
| PE | 실행 파일 형식 |

## 6. 시험 직전 점검

> - L2 스위치는 MAC 주소, 라우터는 IP, L4는 포트 기반.
> - 게이트웨이는 프로토콜이 다른 네트워크를 변환 연결, 병목 가능.
> - VLAN은 브로드캐스트 도메인 분리, 트렁크는 스위치 간 연결, 루프는 STP.
> - 순차 분산은 Round Robin. 헬스 체크는 로드 밸런서의 기본 기능.
> - 리피터는 물리 계층.
> - 네트워크 부팅은 PXE.
