# 셸과 환경 변수

<div class="summary">

- **셸**은 사용자가 입력한 명령을 해석해 커널에 전달하는 프로그램입니다. 로그인 때 받는 셸은 `/etc/passwd`의 7번째 칸에 적혀 있고, 쓸 수 있는 셸의 목록은 `/etc/shells`에 있습니다.
- **환경 변수**는 `$SHELL`(로그인 셸), `PS1`(기본 프롬프트), `PS2`(줄을 이어 쓸 때의 프롬프트)를 구분해 외웁니다.
- **설정 파일**은 범위로 나눕니다. 전체 사용자용은 `/etc/profile`(환경 변수)과 `/etc/bashrc`(alias, 함수), 개인용은 `~/.bash_profile`(로그인 때)과 `~/.bashrc`(alias, 함수)입니다.
- **history**는 `!!`(직전 명령), `!-N`(N번 전 명령), `!?문자열`(문자열이 들어 있는 최근 명령)으로 다시 실행합니다.

</div>

## 1. 셸이란

셸은 사용자와 커널 사이에서 명령을 번역해 주는 프로그램입니다. 키보드로 `ls`를 치면 셸이 이를 읽어 실행하고 결과를 화면에 돌려줍니다. 셸에는 여러 종류가 있고, 시험에는 "누가 언제 만들었는가"와 "어떤 기능이 특징인가"가 나옵니다.

| 셸 | 만든 곳·시기 | 특징 |
|---|---|---|
| Bourne shell (`sh`) | 유닉스 최초의 셸 | 시험에서 "가장 먼저 등장한 셸". 나머지는 이를 기준으로 만들어졌습니다. |
| C shell (`csh`) | 1978년, 버클리 대학의 빌 조이 | 히스토리, alias(별명), 작업 제어. C 언어와 비슷한 문법입니다. |
| Korn shell (`ksh`) | 벨 연구소의 데이비드 콘 | Bourne 셸과 호환되면서 C 셸의 편리한 기능을 가져왔습니다. |
| tcsh | 1981년 등장 | C 셸에 명령행 완성(TENEX 운영체제의 기능)을 합친 셸입니다. |
| bash | GNU 프로젝트, 브라이언 폭스 | Bourne Again Shell. 리눅스의 기본 셸입니다. |
| dash | 데비안 | POSIX를 따르면서 작고 빨라, 데비안·우분투 계열의 `/bin/sh`로 쓰입니다. |

## 2. 로그인 셸 확인과 변경

"로그인 때 받은 셸"과 "지금 실행 중인 셸"은 다를 수 있어서 확인 방법이 서로 다릅니다.

| 알고 싶은 것 | 방법 |
|---|---|
| 로그인 때 부여받은 셸 | `echo $SHELL` 또는 `grep 계정 /etc/passwd`(마지막 칸) |
| 지금 실행 중인 셸 | `ps` (CMD 열) |
| 사용 가능한 셸 목록 | `cat /etc/shells` 또는 `chsh -l` |
| 로그인 셸 변경 | `chsh -s /bin/csh` (결과는 `/etc/passwd`에 저장) |
| chsh 사용법 확인 | `chsh -u` |

```
$ chsh -s /bin/csh        # 로그인 셸을 csh로 변경
$ chsh -l                 # 사용 가능한 셸 목록 확인
$ echo $SHELL             # 로그인 때 받은 셸
```

> **함정** `echo $SHELL`은 "로그인 때 받은 셸"을 보여 줍니다. 로그인한 뒤 다른 셸로 들어가도 값은 바뀌지 않습니다. 지금 쓰는 셸은 `ps`로 봅니다.

## 3. 셸 변수와 환경 변수

변수는 `이름=값`으로 선언합니다. **등호 양옆에 공백을 넣으면 안 됩니다.** 값을 읽을 때는 이름 앞에 `$`를 붙입니다.

```
$ os=linux               # 선언 (bash)
$ echo $os               # linux
$ unset os               # 해제
```

| 명령 | 하는 일 |
|---|---|
| `set` | 선언된 셸 변수를 모두 출력합니다. 셸 변수를 확인할 때의 답입니다. |
| `env`, `printenv` | 환경 변수(`export`된 변수)만 출력합니다. |
| `export 변수` | 변수를 하위 프로세스에도 전달되는 환경 변수로 만듭니다. |
| `unset 변수` | 선언된 변수를 해제합니다. |

`set os=linux`는 C 셸의 선언 방식입니다. bash에서 `set 값`은 위치 매개변수를 바꾸는 명령이어서 변수 선언이 되지 않습니다.

**대소문자를 구분합니다.** `user=kaitman`으로 선언한 뒤 `echo $USER`를 입력하면 `kaitman`이 아니라 로그인한 계정명(예: `ihduser`)이 나옵니다. `USER`는 시스템이 이미 정해 둔 환경 변수이고, 소문자 `user`는 새로 만든 별개의 변수이기 때문입니다. `echo "$user"`라고 쓰면 `kaitman`이 나옵니다.

### 자주 나오는 환경 변수

| 변수 | 내용 |
|---|---|
| `HOME` | 사용자의 홈 디렉터리 |
| `SHELL` | 로그인 셸 |
| `PATH` | 명령어를 찾는 디렉터리 목록 |
| `USER` | 로그인한 계정 이름 |
| `LANG` | 언어와 문자 셋 (예: `ko_KR.UTF-8`) |
| `TERM` | 터미널 종류 |
| `PS1` | 기본 프롬프트 모양 |
| `PS2` | 줄을 이어 쓸 때의 프롬프트. 줄 끝에 역슬래시(`\`)를 쓰고 Enter를 누르면 나타나는 `>` |
| `MAIL` | 사용자의 메일 파일 경로 (예: `/var/spool/mail/ihduser`) |
| `HISTSIZE` | 메모리에 기억하는 명령 개수 |
| `HISTFILESIZE` | `.bash_history` 파일에 저장하는 명령 개수 |
| `TMOUT` | 입력이 없을 때 자동 로그아웃까지의 초 |

`PS1`의 기본값 `[\u@\h \W]\$`에서 `\u`는 사용자, `\h`는 호스트, `\W`는 현재 디렉터리 이름, `\$`는 `$`(root는 `#`)를 뜻합니다.

## 4. 환경 설정 파일

핵심은 **적용 범위**(전체 사용자 또는 개인)와 **내용**(환경 변수 또는 alias와 함수)을 짝지어 외우는 것입니다.

| 파일 | 대상 | 내용 |
|---|---|---|
| `/etc/profile` | 모든 사용자 | 로그인 때 읽는 환경 변수와 시작 프로그램 |
| `/etc/bashrc` | 모든 사용자 | alias와 함수 |
| `~/.bash_profile` | 개인 | 로그인 때 읽는 환경 변수와 시작 프로그램 |
| `~/.bashrc` | 개인 | alias와 함수 |
| `~/.bash_logout` | 개인 | 로그아웃할 때 실행할 내용 |
| `~/.bash_history` | 개인 | 실행한 명령 목록(로그아웃할 때 저장) |

alias를 정의해도 그 셸을 닫으면 사라집니다. **다음 로그인에도 계속 쓰려면 `~/.bashrc`에 적습니다.**

> **함정** 파일 이름 앞의 점입니다. `~/.bashrc`가 맞고 `~/bashrc`는 틀립니다. 홈 디렉터리의 설정 파일은 모두 점으로 시작하는 숨김 파일입니다.

## 5. 편의 기능

| 기능 | 사용법 |
|---|---|
| 명령행 완성 | 파일명 앞부분만 입력하고 `Tab`을 누르면 나머지를 채웁니다. |
| alias (별명) | `alias hd='ls ~'`처럼 긴 명령을 짧은 이름으로 만듭니다. 해제는 `unalias 이름` |
| 원래 명령 실행 | alias가 걸린 `ls` 대신 원래 명령을 쓰려면 앞에 역슬래시를 붙여 `\ls` |
| history | 위/아래 방향키로 이전 명령을 불러와 고쳐서 다시 실행합니다. |

### history 재실행

| 입력 | 의미 |
|---|---|
| `history` | 저장된 전체 명령 목록 |
| `history 5` | 최근에 실행한 명령 5개만 출력 |
| `!!` | 직전에 실행한 명령을 다시 실행 |
| `!N` | 목록의 N번 명령을 실행 |
| `!-N` | 현재부터 N번째 전에 실행한 명령을 실행 |
| `!문자열` | 해당 문자열로 시작하는 가장 최근 명령 |
| `!?문자열` | 해당 문자열이 들어 있는 가장 최근 명령 |

## 6. 시험 직전 점검

> - 가장 먼저 등장한 셸은 Bourne shell, 히스토리·alias·작업 제어를 처음 넣은 셸은 C shell(빌 조이, 1978년)입니다.
> - 선언된 변수를 모두 보는 명령은 `set`, 환경 변수만 보는 명령은 `env`입니다.
> - 로그인 셸이 바뀌면 `/etc/passwd`가 바뀝니다. `/etc/shells`는 쓸 수 있는 목록일 뿐 바뀌지 않습니다.
> - "전체 사용자 + alias, 함수"는 `/etc/bashrc`, "전체 사용자 + 환경 변수, 시작 프로그램"은 `/etc/profile`입니다.
