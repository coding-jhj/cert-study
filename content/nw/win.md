# 윈도 서버 (Active Directory·DNS·DHCP·IIS·Hyper-V)

<div class="summary">

- **관리 도구 실행 명령**: 이벤트 뷰어 `eventvwr.msc`, 컴퓨터 관리 `compmgmt.msc`, 로컬 보안 정책 `secpol.msc`, **인증서 `certmgr.msc`**, 장치 관리자 `devmgmt.msc`, 그룹 정책 `gpedit.msc`, 성능 모니터 `perfmon`, **IIS 관리자 `inetmgr`**, 방화벽 `wf.msc`.
- **IP 명령**: `ipconfig /all`(전체 설정), `/renew`(재할당), `/release`(반납), `/flushdns`(DNS 캐시 초기화), `/displaydns`(캐시 보기). `netstat -r`(라우팅), `-b`(프로세스 실행 파일).
- **Active Directory**: 도메인 간 접근은 **트러스트**, 부서 단위 분할은 **OU**, 포리스트 전체 그룹은 **유니버설 그룹**, 사용자 관리 명령은 `dsadd`, `dsmod`, `dsrm`.
- **DNS 레코드**: A, AAAA, **CNAME**(별칭), MX(메일), NS(네임서버), PTR(역방향), SOA. **Round Robin**은 여러 IP를 번갈아 응답합니다.
- **Hyper-V**: **검사점(Checkpoint)** 으로 특정 시점을 저장·복원하고, 실행 중인 가상 하드디스크를 다른 저장소로 이동할 수 있습니다.

</div>

## 1. 관리 도구와 명령

| 하려는 일 | 명령 / 도구 |
|---|---|
| 종료·재부팅 **기록** 확인 | **이벤트 뷰어** (`eventvwr.msc`) |
| 인증서 관리자 호출 (키 복원) | **`certmgr.msc`** |
| 컴퓨터 관리 | `compmgmt.msc` (`compmgmt`만 입력하는 형태는 올바른 연결로 보지 않음) |
| 로컬 보안 정책 | `secpol.msc` |
| 장치 관리자 | `devmgmt.msc` |
| 로컬 그룹 정책 편집기 | `gpedit.msc` |
| 성능 모니터 (일정 주기로 데이터 수집) | `perfmon` |
| 고급 방화벽 | `wf.msc` |
| 시스템 구성 | `msconfig` |
| **IIS 관리자** | `inetmgr` |
| Active Directory 관리 센터 | `dsac.exe` |

**리소스 모니터**는 **CPU, 메모리, 디스크, 네트워크**의 사용량을 실시간으로 봅니다. **방화벽**은 점검 항목이 아닙니다.

**이벤트 뷰어 Windows 로그**: 응용 프로그램, 보안, 설치, 시스템, 전달된 이벤트. 하드웨어 이벤트, 인터넷 익스플로러, Windows PowerShell은 Windows 로그 하위 항목이 아니라 응용 프로그램 및 서비스 로그 쪽입니다.

### 네트워크 명령

| 명령 | 기능 |
|---|---|
| `ipconfig /all` | Host Name, IP, 서브넷 마스크, DNS 서버, 기본 게이트웨이 등 전체 설정 |
| `ipconfig /renew` | DHCP에서 새 IP 주소 갱신(재할당) |
| `ipconfig /release` | 할당된 IP 반납 |
| `ipconfig /flushdns` | **DNS 캐시 초기화** (이전 도메인으로 계속 접속될 때) |
| `ipconfig /displaydns` | DNS 캐시 보기 |
| `netstat -r` | 라우팅 테이블 |
| `netstat -b` | 열린 포트와 연관된 **실행 파일(프로세스)** |
| `netstat -a`, `-n`, `-s` | 모든 연결, 숫자 표시, 프로토콜별 통계 |
| `tracert` | 목적지까지 거치는 게이트웨이 순서 |

> **함정** `netstat`은 인터페이스 구성, 라우팅 테이블, 네트워크 인터페이스 상태를 보여 주지만 **패킷이 방문하는 게이트웨이의 순서는 `tracert`** 입니다. DNS 서버 설치 전 고정 IP 경고가 나올 때 `ipconfig /renew`는 해결 방법이 아닙니다. 고정 IP로 바꿔야 합니다.

## 2. 사용자와 그룹

기본 로컬 계정은 **Administrator, DefaultAccount, Guest**입니다. **root는 리눅스 계정**입니다.

| 그룹 | 권한 |
|---|---|
| **Administrators** | 모든 권한 |
| Backup Operators | 파일 백업과 복구 |
| **Guests** | 로그인할 때 임시 프로필을 만들고 로그아웃하면 삭제, 기본적으로 사용 안 함 |
| **Users** | 사용자 계정 생성 시 기본 소속 그룹, **시스템 수준 변경 권한은 없음** |
| Power Users | Administrator와 같은 권한이 아님 (이전 호환용) |
| **Remote Management Users** | **WMI** 자원 관련 권한 |
| **Access Control Assistance Operators** | 컴퓨터 자원에 대한 **인증 속성**을 관리(읽는) 권한 |
| Performance Monitor Users | 성능 카운터 관련 |
| RDS Endpoint Servers | 원격 데스크톱 서비스 관련 |
| Replicator | 파일 복제 |

> **함정** Users 그룹이 "시스템 수준의 변경 권한을 갖는다"는 설명은 틀립니다.

### 인증과 암호화

| 기능 | 설명 |
|---|---|
| **BitLocker** | **디스크(드라이브) 전체 암호화**. 디스크가 도난당해도 키 없이 읽을 수 없음. FileVault는 macOS 기술 |
| **EFS** | 파일 단위 암호화. 인증서 확장자 **CER, P7B, PFX, SST** 지원. 시스템을 다시 설치하면 키가 없어 열 수 없음. 개인키는 암호 외에도 보호 가능 |

## 3. Active Directory

| 용어 | 설명 |
|---|---|
| **도메인 컨트롤러(DC)** | 인증을 수행하는 서버 |
| **트러스트(Trust)** | 도메인 또는 포리스트 사이에서 **신뢰 여부를 나타내는 관계**. 서로 다른 도메인 클라이언트와 서버 간 **인증과 권한 부여**를 제공. 포리스트 안의 도메인 사이에는 **양방향 전이** 트러스트 |
| **OU (조직 구성 단위)** | 한 도메인 안에서 관리부, 회계부, 기술부처럼 **세부 단위로 나눔** |
| 사이트(Site) | 물리적 위치 기반 구성 |
| 포리스트, 트리 | 도메인의 집합과 계층 |
| 유니버설 그룹 | **포리스트 전체**에서 사용, 여러 도메인의 사용자와 그룹을 포함 가능 |
| 글로벌/도메인 로컬 그룹 | 도메인 단위 범위 |

**역할**: 사용자 인증과 디렉터리 기반의 자원 관리입니다. IP 자동 할당(DHCP)이나 방화벽 자동 구성이 아닙니다.

**도메인 사용자 계정 관리 명령**: `dsadd`, `dsmod`, `dsrm`. `net user`는 로컬 계정 관리이며 도메인 사용자 관리 명령으로 보지 않습니다. 계정은 **Active Directory 사용자 및 컴퓨터**에서 만들고 보안 그룹에 추가합니다.

**그룹 정책**: 암호 길이·복잡성, 계정 잠금을 강제할 수 있고, 어느 PC에서 로그온해도 동일한 환경(폴더 리디렉션, 프로필 등)을 제공할 수 있으며 **소프트웨어도 배포할 수 있습니다**.

## 4. DNS 서버

| 레코드 | 기능 |
|---|---|
| **A** | 정규화된 도메인 이름 → **32비트 IPv4** |
| **AAAA** | 도메인 이름 → **128비트 IPv6** |
| **CNAME** | 실제 도메인 이름과 연결되는 **가상 도메인 이름**(별칭, 서브 도메인 등록이라고 하면 틀림) |
| **MX** | 메일 서버(메일 라우팅 정보) |
| **NS** | 네임 서버 |
| **PTR** | IP 주소 → FQDN (**역방향**) |
| **SOA** | 존의 첫 레코드 |

> **함정** "주어진 사서함에 도달하는 라우팅 정보"는 NS가 아니라 **MX** 레코드의 기능입니다. 정방향은 도메인 → IP, **역방향 조회는 IP → 도메인**입니다.

**SOA 필드**: 일련번호(영역 파일의 개정 번호), 주 서버(영역이 초기에 설정되는 서버), **책임자**(관리자의 전자 메일 주소지만 `@` 대신 마침표를 써서 적음), 새로 고침 간격(보조 서버가 주 서버의 변경을 검사하기 전에 대기하는 시간).

**Round Robin**: 여러 대의 웹 서버를 운영할 때 질의하면 설정 순서대로 돌아가며 IP를 알려 줍니다.

**TTL**: DNS 레코드의 캐싱 주기입니다. 짧게 하면 질의가 늘어 서버 부하가 커질 수 있고, 길게 하면 IP가 바뀔 때 갱신이 늦어집니다. **TTL을 설정하지 않아도 정방향 조회는 가능**합니다.

**DNSSEC**: DNS 응답의 **무결성과 출처 인증**을 제공합니다. 성능 캐싱이 아니고 쿼리 전체를 암호화하는 것도 아닙니다.

## 5. DHCP 서버

| 사실 | 내용 |
|---|---|
| 역할 | **IP 자원의 효율적 관리와 자동 할당** (이름 확인은 DNS, 사설-공인 변환은 NAT) |
| 임대 기간 | 일, 시간, 분 단위로 설정 |
| 지연 시간 | 주소를 분배할 때 적용할 지연 시간은 **ms 단위** |
| 클라이언트 | 부팅 시 DHCP 서버를 찾는 **브로드캐스트** |
| 포트 | UDP 67/68 (53은 DNS) |
| 환경 | Active Directory 없이도 구성 가능 |
| 예약 | DHCP와 BOOTP 지원 |
| **MCLT** | Failover 환경에서 **파트너 서버가 기존 임대를 임시로 갱신할 수 있는 최대 시간** |

## 6. IIS 웹 서버

| 항목 | 내용 |
|---|---|
| 기본 | HTTP 80, HTTPS 443 |
| 사이트 구분 | IP 주소, 포트, **호스트 이름** 바인딩으로 구분. 하나의 서버에서 여러 사이트 운영 가능(IP를 반드시 다르게 할 필요 없음) |
| 기본 웹사이트 등록 정보 | IP 주소, **TCP 포트**(시리얼 포트가 아니라 TCP 포트 번호), 연결 수 제한, 연결 시간 제한 |
| 홈 디렉터리 | 기본값은 `C:\inetpub\wwwroot`지만 **다른 경로로 바꿀 수 있음** |
| 기본 문서 | 추가 메뉴로 추가 가능 |
| 디렉터리 검색 | 제공할 문서가 없을 때 보여 줄 항목 지정 |
| 가상 디렉터리 | 별칭을 만들고 실제 경로를 선택 |
| 요청 필터링 | 특정 요청을 차단 |
| HTTPS | 지원 |
| PHP | 실행 가능 |
| 응용 프로그램 풀 | 여러 웹 사이트를 호스팅 가능 |
| 로그 | 저장 위치 변경 가능. W3C 외 형식도 지원. 실시간이 아님. 최대치에 도달해도 자동으로 이전 로그를 삭제하지 않음 |
| FTP 서버 | **서버 관리자의 역할 및 기능 추가**에서 Web Server (IIS)의 **FTP Server** 역할 서비스를 선택해 설치(PowerShell로도 가능). IIS FTP만으로 SFTP는 구성할 수 없음 |

## 7. Hyper-V와 컨테이너

| 항목 | 내용 |
|---|---|
| 효과 | 하드웨어 **사용률 향상**, 유지비용 절감, 개발·테스트 효율 향상, **서버 가용성 향상** |
| 기능 | 가상 컴퓨터를 다른 서버로 **복제** 가능, 하나의 물리 서버에서 **여러 가상 컴퓨터** 사용, 가상 하드디스크를 **실행 중에도 다른 저장소로 이동** 가능 |
| **검사점(Checkpoint)** | 가상 머신의 **특정 시점 상태를 저장**하고 복원 (악성코드 실행 전 시점으로 되돌릴 때). 가상 스위치는 네트워크 연결, 내보내기는 VM을 파일로 저장 |
| **Windows 컨테이너** | 작은 운영 환경을 포함하는 경량 가상화. 가상 컴퓨터보다 가볍게 생성·운영 (Hyper-V 가상머신은 완전한 OS를 포함해 무거움) |

## 8. 기타 서버 기능

| 기능 | 설명 |
|---|---|
| **WAP (Web Application Proxy)** | DirectAccess나 VPN과 달리 원격 컴퓨터를 네트워크에 연결하지 않고 **내부 웹 리소스를 인터넷에 게시** |
| PPTP, L2TP, SSTP | VPN 터널링 프로토콜 |
| 클라우드 폴더(Work Folders) | 더 많은 위치와 다양한 장치에서 데이터에 접근 |
| **SAN** | 공통 저장소를 중앙에서 관리, **파이버 채널**, 대용량 **블록 기반** 전송, LAN과 독립적인 백업·복구 |
| NAS | 네트워크에 연결한 파일 저장소 |
| **PowerShell** | 기존 **DOS 명령도 사용 가능**, 콘솔에서 대화형 사용, 텍스트 스크립트, **대소문자 구분 안 함** |
| 파일 및 프린터 서버 | **TCP/IP** 필수 |

## 9. 시험 직전 점검

> - 인증서 `certmgr.msc`, IIS `inetmgr`, 성능 `perfmon`, 종료 기록은 이벤트 뷰어.
> - DNS 캐시 비우기 `ipconfig /flushdns`, IP 갱신 `/renew`, 전체 정보 `/all`.
> - 도메인 간 권한은 트러스트, 부서 분할은 OU, 포리스트 전체는 유니버설 그룹.
> - CNAME은 별칭, PTR은 역방향, MX가 메일 라우팅.
> - 검사점은 시점 복원, 라운드 로빈은 IP를 번갈아.
> - BitLocker는 디스크 전체 암호화, EFS는 파일 암호화.
> - netstat -r 라우팅, -b 프로세스 실행 파일.

## 10. OX 점검

| 문장 | 답 | 이유 |
|---|---|---|
| `netstat`은 패킷이 방문하는 게이트웨이 순서를 보여 준다. | X | `tracert`입니다. |
| 역방향 조회는 IP 주소를 주면 도메인을 반환한다. | O | |
| NS 레코드는 사서함 라우팅 정보를 제공한다. | X | MX입니다. |
| 그룹 정책으로 소프트웨어를 배포할 수 있다. | O | |
| PowerShell에서는 기존 DOS 명령을 쓸 수 없다. | X | 쓸 수 있습니다. |
| IIS 기본 웹사이트의 홈 디렉터리는 반드시 `C:\inetpub\wwwroot`여야 한다. | X | 변경할 수 있습니다. |
| 검사점은 VM의 특정 시점 상태를 저장하고 되돌린다. | O | |
| DHCP 서버의 기본 포트는 DNS와 같은 53번이다. | X | UDP 67/68입니다. |
| Users 그룹은 시스템 수준 변경 권한을 가진다. | X | 가지지 않습니다. |
| BitLocker는 디스크 전체를 암호화한다. | O | |
