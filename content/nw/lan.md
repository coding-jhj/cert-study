# LAN·토폴로지·이더넷

<div class="summary">

- **토폴로지**: 스타(중앙 제어, **확장 쉬움**, 중앙 장애에 취약), 버스(**터미네이터**), 링(확장 어려움, 한 장치 오류가 전체에 영향), 메시(우회 경로, 임시망 구성 가능).
- **매체 접근**: **CSMA/CD**(이더넷, 충돌 감지 후 재전송), 토큰 방식(**Token Ring**, 순차적으로 전송 기회 부여), **CSMA/CA**(무선).
- **이더넷 속도**: Fast Ethernet(100BASE-T, 100Mbps), Gigabit(1000BASE-T는 **UTP**, 1000BASE-SX는 **광**).
- **교환 방식**: 회선, 패킷(가상회선·데이터그램), 메시지. **가상회선**은 경로를 설정하고 전송이 없으면 해제합니다.
- **VLAN**은 하나의 스위치를 여러 **브로드캐스트 도메인**으로 나눕니다. **VPN**은 터널링으로 공중망을 사설망처럼 씁니다.

</div>

## 1. 토폴로지

| 형태 | 특징 |
|---|---|
| **스타(성형)** | 중앙 제어점과 **점 대 점(point-to-point)** 연결. 단말 **추가·제거가 쉽고 중앙 관리**가 가능. 각 단말은 **중앙을 통해** 데이터 교환. **중앙 장치가 고장나면** 전체에 영향 |
| **버스** | 하나의 회선을 공유. **터미네이터**가 신호의 반사를 막음. 스타보다 케이블이 적게 듦 |
| **링(Ring)** | 노드를 원형으로 연결. 한 통신 장치의 오류가 전체에 영향. 장애 발견은 쉽지만 **확장성은 좋지 않음**. 토큰이 순차 전달 |
| **메시(Mesh)** | 하나의 연결이 끊겨도 **자동으로 다른 연결로 전송**. 일대일 **다중 홉 라우팅**. 노드 이동이 자유로워 토폴로지가 동적으로 변함. **중앙 제어나 표준 서비스 없이도 임시로 망을 구성**할 수 있음 |
| 트리 | 계층적 구조 |

> **함정** "하나의 단말 장치가 고장나면 전체 통신망에 영향을 줄 수 있다"는 스타형의 설명으로는 틀립니다(중앙 장치가 고장나야 영향). "링형은 확장성이 뛰어나다"도 틀립니다. 메시를 "중앙 제어 없이 임시로 구성할 수 없다"고 하면 틀립니다.

## 2. 매체 접근 제어(MAC)

| 방식 | 동작 |
|---|---|
| **CSMA/CD** | 다른 송신자가 사용하는지 **점검**, 아무도 쓰지 않으면 **바로 전송**, **충돌**하면 충돌 신호를 전송한 뒤 **임의의 시간 대기 후 재전송**. 지연 시간을 예측하기 어려움. **충돌 도메인이 작을수록** 좋음. **토큰 권한이 필요하지 않음** |
| **Token Ring / Token Passing** | **토큰**이라는 비트 패턴이 원형으로 순차 전달, **모든 노드가 공평하게** 전송 기회를 받음 |
| CSMA/CA | 충돌을 피하는 방식(무선) |
| Demand Priority | 허브가 요청을 중재 |
| DQDB | MAN 방식 |

## 3. 이더넷

| 이름 | 속도와 특징 |
|---|---|
| Ethernet | 10Mbps |
| **Fast Ethernet** | **100BASE-T**, **100Mbps**, CSMA/CD |
| **Gigabit Ethernet** | 1Gbps. 기존 이더넷과 고속 이더넷과 **호환** |
| 10Gigabit Ethernet | 10Gbps |
| Thick Ethernet | 굵은 동축 케이블 이더넷 |

| 규격 | 매체 |
|---|---|
| **1000BASE-T** | **UTP**(비차폐 꼬임쌍선), IEEE 802.3ab, **최대 1000Mb/s**(Kb/s가 아님), 스위치 중심 스타 |
| **1000BASE-SX** | **광케이블** 기가비트 이더넷 |
| 10GBASE-T | 10Gbps 꼬임쌍선 |
| 10GBASE-SR, 10GBASE-LRM | 10Gbps **광섬유**. 구리 Gigabit Ethernet에서 **Optical Fiber Cable**로 업그레이드하는 환경 |

SAN의 대역폭이 부족해 10GBASE-SR 또는 10GBASE-LRM으로 가려면 매체는 **광섬유 케이블**입니다(CAT.3, CAT.5, 얇은 동축은 부적합).

### FDDI

광섬유를 쓰는 **토큰 패싱** 방식의 **이중 링** 토폴로지입니다. 한 개의 링이 아닙니다.

| 부계층 | 역할 |
|---|---|
| PMD (Physical Medium Dependent) | 광섬유 종류별 전송 장비 내역 |
| PHY (Physical Sublayer) | 부호화와 고장난 노드의 처리 방식 |
| SMT (Station Management) | 네트워크 고장을 탐지하고 고장이 발견되면 링을 재구성 |

### IEEE 802 표준

| 표준 | 내용 |
|---|---|
| 802.3 | 이더넷, **CSMA/CD** |
| 802.4 | 토큰 버스 |
| 802.5 | 토큰 링 |
| **802.11** | **무선 LAN** |

## 4. 교환 방식

| 방식 | 설명 |
|---|---|
| 회선 교환 | 통신 동안 회선을 점유 |
| **패킷 교환** | 메시지를 **짧은 패킷으로 나눠** 전송. 연결 설정에 따라 **가상회선**과 **데이터그램**으로 분류. 회선 차단(블로킹)이 없음 |
| **가상회선** | 전송 전에 **경로를 설정**하고 정해진 단위로 전송, **규정된 시간 내에 전송 데이터가 없으면 경로를 해제** |
| 데이터그램 | 경로를 미리 설정하지 않음 |
| 메시지 교환 | 메시지 단위로 저장 후 전달 |

> **함정** 패킷 교환망은 유입 데이터가 많아질수록 전송 속도가 **빨라지지 않습니다**(혼잡해지면 느려집니다).

## 5. VPN, NAT, 보안

| 개념 | 설명 |
|---|---|
| **VPN** | 인터넷 같은 공중망을 특정인이나 조직이 **사설망처럼** 쓰게 함. 본사-지사를 전용선으로 구축하는 것보다 **훨씬 적은 비용** |
| **터널링(Tunneling)** | VPN 구현 기술. 두 호스트 간에 외부의 영향을 받지 않는 **가상 경로**를 설정 |
| 인증, 암호화, 접근 통제 | VPN의 다른 구성 기술 |
| **NAT** | 사설 IP와 공인 IP를 변환해 공인 IP 사용을 효율화 |
| **NAC** | 단말이 네트워크에 접근하기 전 **보안 정책 준수 여부**와 IP/MAC 인가 여부를 검사하고, 단말 정보를 수집해 그룹으로 분류하고 위협 정도에 따라 제어 |
| NIC, F/W, IPS | 각각 랜카드, 방화벽, 침입 방지 시스템 |

## 6. VLAN과 VTP

**VLAN**: 하나의 물리 스위치에 연결된 장치들을 여러 개의 **논리적 브로드캐스트 도메인**으로 분리합니다. STP는 루프 방지, LACP는 링크 묶음, VTP는 VLAN 정보 전달입니다.

**VTP의 3가지 모드**: server, client, transparent. interface mode는 없습니다.

## 7. 기타

**SIP**(Session Initiation Protocol): IETF의 **시그널링** 프로토콜로 음성과 화상 같은 멀티미디어 세션을 생성·수정·종료합니다. 요구/응답 구조, TCP와 UDP 모두 사용, 이메일과 비슷한 SIP URI로 사용자를 구분하므로 IP 주소에 종속되지 않습니다.

**BGP**: **경로 벡터** 방식으로 동작하고 경로 선택 시 **정책 기반 필터링**을 적용할 수 있습니다(AS 간 라우팅).

## 8. 시험 직전 점검

> - 스타는 중앙 관리와 확장이 쉽고 중앙 고장에 취약. 링은 확장이 어렵다.
> - CSMA/CD는 토큰이 필요 없고 충돌 후 임의 대기. 토큰 방식은 공평한 순차 전송.
> - Fast Ethernet 100Mbps, 1000BASE-T는 UTP, 1000BASE-SX는 광.
> - 가상회선은 경로 설정 후 전송, 전송이 없으면 해제.
> - 패킷 교환은 블로킹이 없고 데이터가 많아진다고 빨라지지 않음.
> - VLAN은 브로드캐스트 도메인 분리, VTP는 server, client, transparent.
> - 802.3 이더넷, 802.5 토큰 링, 802.11 무선 LAN.
