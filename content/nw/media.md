# 전송 매체·RAID·보안 장비

<div class="summary">

- **광케이블**: 코어(Core)와 클래딩(Cladding)으로 구성, 멀티 모드와 싱글 모드, **신호 손실이 적고 전자기 간섭이 없으며 대역폭이 가장 넓습니다**. 끊어지면 별도 장비 없이 이을 수 없습니다.
- **RAID**: RAID 0 스트라이핑(가장 빠름, 중복 없음), **RAID 1 미러링**, **RAID 5 회전 패리티**. RAID는 디스크 여러 개를 하나의 논리 디스크처럼 씁니다(메모리 용량 증가 아님).
- **PoE**: UTP 케이블로 데이터와 **직류 48V 전원**을 함께 보냅니다(AP, CCTV).
- **FTTH의 PON**: 방송형, 모든 가입자가 같은 광신호를 수신하고 상향은 TDMA로 경쟁합니다.
- **NAC**는 접속 장치를 인가 여부로 제어, **WAF**는 웹 서버 보호, **방화벽**은 정책에 따라 통과 트래픽을 허용·차단합니다.

</div>

## 1. 전송 매체

| 매체 | 특징 |
|---|---|
| **광케이블(광섬유)** | **코어(Core)** 와 이를 감싸는 굴절률이 다른 유리·플라스틱 **클래딩(Cladding)** 으로 구성, 빛으로 전송. **멀티 모드형과 싱글 모드형**. **보안과 잡음에 강함**, **신호 손실이 적고 전자기 간섭이 없음**, 수 Km 이상도 전송 가능. **대역폭이 가장 넓음** |
| 꼬임쌍선(UTP/STP) | 여러 라인을 묶어 쓰면 간섭을 줄일 수 있고 8핀 중 4핀을 송수신에 사용 |
| 동축 케이블 | Base Band, CATV 동축 등 |
| 2선식 개방 선로 | 단순한 두 가닥 선로 |

> **함정** 광케이블은 동축 케이블처럼 단선되었을 때 **별도의 장비 없이 선을 연결해 쓸 수 없습니다**. "수 Km 이상 전송 시 Repeater를 반드시 사용한다"는 광섬유의 특성이 아닙니다.

### FTTH (Fiber-To-The-Home)

| 방식 | 설명 |
|---|---|
| **PTP** | 점 대 점 연결 |
| **AON** | 능동 광 네트워크 |
| **PON** | 수동 광 네트워크. 모든 가입자가 **동일한 광신호를 수신**하는 방송형 성격. 하향 트래픽은 모든 ONU/ONT가 수신하고 상향은 **경쟁**하며 충돌 방지에 **TDMA** 사용 |

### PoE (Power over Ethernet)

전원부(어댑터)를 따로 연결하지 않고 **UTP 케이블로 데이터와 전원을 동시에** 보냅니다. 표준 전압은 **직류 48V**이며 **AP나 CCTV 카메라** 설치에 많이 씁니다. L2 스위치, IP 공유기, UPS는 이 설명에 맞지 않습니다.

## 2. RAID

여러 개의 디스크를 묶어 **하나의 디스크처럼** 사용합니다(Redundant Array of Independent/Inexpensive Disks). 여러 디스크에 일부 **중복된 데이터를 나눠 저장**하고, 읽기/쓰기 속도를 높이며, 데이터를 안전하게 지킬 수 있고, 가동 중에 디스크가 고장나도 **시스템 정지 없이 교체**할 수 있습니다.

| 레벨 | 방식 | 특징 |
|---|---|---|
| **RAID 0** | **스트라이핑(Striping)** | 최소 **2개** 이상의 디스크에 동시에 분산 저장, **속도가 가장 빠름**, 중복이 없어 **디스크 하나만 손상돼도 전체 데이터 복구 불가** |
| **RAID 1** | **미러링(Mirroring)** | 같은 데이터를 두 디스크에 저장, 성능과 고장 대비가 가장 뛰어난 것으로 출제 |
| RAID 3, 4 | 전용 패리티 디스크 | 패리티 디스크에 병목 |
| **RAID 5** | **회전(분산) 패리티** | 패리티를 디스크에 돌아가며 저장해 **병목 현상을 줄임** |
| Linear RAID | 디스크를 이어 붙임 | |

> **함정** RAID는 **메모리(RAM) 용량을 늘리지 않습니다**. "운영체제에서 여러 논리적 드라이브를 하나의 물리적 드라이브로 활용"한다는 설명은 반대로 쓴 것입니다. RAID는 여러 물리 디스크를 하나의 논리 디스크처럼 씁니다.

## 3. 보안 장비와 기술

| 장비 / 기술 | 설명 |
|---|---|
| **NAC (Network Access Control)** | 네트워크에 접속하는 장치를 제어. **인가된 사용자만 내부망**에 접속하고 인가 전이나 승인 실패 시 접속 불가 |
| **WAF (Web Application Firewall)** | **웹 서버 전용 보안 장비**로 HTTP, HTTPS 같은 웹 프로토콜 공격을 방어 |
| **방화벽** | 사전에 정의된 **보안 정책과 접근 제어 규칙**에 따라 트래픽을 허용하거나 차단 |
| IDS / IPS | 침입 탐지 / 침입 방지 |
| NAT | 내부 사설 IP, 외부 공인 IP로 변환. IP 주소 부족과 내부 주소 보안에 쓰임 |

> **함정** 방화벽은 **자신을 통과하지 않는 트래픽은 감시·제어할 수 없고**, 내부에서 발생하는 모든 공격을 완전히 차단하지 못합니다. 판단 기준은 IP 주소만이 아니라 포트와 프로토콜 등 정책입니다. NAC를 NAT(Network Address Translation)와 혼동하지 않습니다.

## 4. 시험 직전 점검

> - 광케이블: 코어와 클래딩, 손실 적음, 간섭 없음, 대역폭 최대, 장비 없이 이을 수 없음.
> - RAID 0 스트라이핑(복구 불가), RAID 1 미러링, RAID 5 회전 패리티.
> - PoE는 UTP로 48V 전원. PON은 방송형 TDMA.
> - NAC는 접속 제어, WAF는 웹 보호, 방화벽은 정책 기반.
